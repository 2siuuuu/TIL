아래 코드에서 지역 변수, 인스턴스 필드, 정적 필드가 어떤 형태인지 알 수 있다.
```java
public class City {  
    private String name; // Instance Field 
    static private int id;  // Static Field
    
    public City(String name) {  
        // city가 3개 이상 생성되는 것을 방지한다.  
        if(this.id != 3) {  
            this.name = name;  
            this.id += 1;  
        }  
    }
    
    public void testmethod() {
        int num = 1; // Local variable
        System.out.println("숫자: " + num);
    }
}
```

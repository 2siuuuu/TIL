---

## 🌏 전체 그림 한 줄 요약

> **IDE(개발 도구)** 안에서 개발자가 작성한 **코드**는  
> **JDK**를 통해 컴파일되고  
> **JRE**를 통해 실행되며  
> 그 실행의 실제 엔진은 **JVM**이다.

---

## 1️⃣ JVM (Java Virtual Machine)

> **"자바 프로그램이 실제로 돌아가는 가상 컴퓨터"**

- 역할: `.class` 파일(바이트코드)을 읽어서 실행시킴.
    
- 즉, 자바 코드가 **운영체제 위에서 직접 도는 게 아니라**, JVM 위에서 돌아가는 것.
    
- 운영체제에 따라 JVM이 다르게 구현되어 있어서,  
    자바 프로그램은 **한 번 작성하면 어디서든 실행 가능 (Write Once, Run Anywhere)**
    

📦 **JVM이 하는 일**

- 바이트코드 해석 및 실행
    
- 메모리 관리 (Garbage Collection)
    
- 스레드 관리
    
- 예외 처리
    

---

## 2️⃣ JRE (Java Runtime Environment)

> **"JVM이 잘 작동하도록 돕는 실행 환경"**

- 이름 그대로, **Run(실행)**을 위한 환경이야.
    
- JRE는 내부에 **JVM**과 *_필요한 라이브러리(java._ 패키지들)**를 포함함.
    
- 즉, 자바 프로그램을 “**실행만 하고 싶을 때**” 필요한 게 JRE야.
    

💡 예시

- 네가 자바로 만든 프로그램을 친구한테 줬을 때,  
    그 친구는 코드를 수정할 필요 없이 실행만 하면 되잖아?  
    → 그 친구는 **JRE**만 있으면 됨.
    

---

## 3️⃣ JDK (Java Development Kit)

> **"자바를 개발하기 위한 도구 세트"**

- 개발자가 코드를 **작성하고, 컴파일하고, 디버깅**할 때 사용하는 **전체 개발 도구 세트**.
    
- JDK 안에는 **JRE**가 포함되어 있고,  
    추가로 **javac (컴파일러)**, **jar**, **javadoc** 같은 **개발용 유틸리티**들이 들어있어.
    

💡 예시

- `.java` → (JDK의 `javac`) → `.class`
    
- 그 후 `.class` → (JRE의 JVM) → 실행
    

즉,

- **JDK = 개발용 + 실행용 (JRE 포함)**
    
- **JRE = 실행용만**
    

---

## 4️⃣ IDE (IntelliJ IDEA, Eclipse 등)

> **"개발을 편하게 해주는 통합 개발 환경"**

- IDE는 **JDK를 내부적으로 사용**해. (JDK가 없으면 IDE가 제대로 작동 안 해)
    
- 코드를 자동 완성하거나, 실행 버튼을 눌렀을 때 자동으로 `javac`, `java` 명령을 호출함.
    
- 즉, IDE는 **JDK의 기능을 편리하게 쓰도록 감싸주는 껍데기(UI)**라고 보면 돼.
    

💡 예시  
IntelliJ에서 “Run” 버튼 클릭 →  
👉 IDE가 내부적으로 `javac`로 컴파일  
👉 JRE의 JVM을 통해 실행  
👉 결과 콘솔에 출력

---

## 🔁 관계를 한눈에 보기

```
IDE (IntelliJ, Eclipse 등)
 └── 사용 → JDK (개발 도구 세트)
       ├── 포함 → JRE (실행 환경)
       │       └── 포함 → JVM (실행 엔진)
```

---

## 🌳 비유로 정리하자면

|구성요소|비유|역할|
|---|---|---|
|**JVM**|‘자바 프로그램이 실제로 돌아가는 기계’|프로그램 실행|
|**JRE**|‘기계가 작동할 수 있도록 전기, 부품, 연료를 제공하는 환경’|실행 환경 제공|
|**JDK**|‘기계를 조립하고 테스트할 수 있는 공구 세트’|개발 도구|
|**IDE**|‘공구를 편하게 쓸 수 있게 만든 스마트 작업대’|개발 편의성 제공|

---

## 💬 한 줄로 요약하자면

> **IDE**는 **JDK**를 사용하고,  
> **JDK**는 **JRE**를 포함하며,  
> **JRE**는 **JVM**을 포함한다.
> 
> 💡 **JVM이 중심이고, 나머지는 그걸 둘러싼 껍질이다.**

# Java가 해결한 문제
**플랫폼 종속성** 
자바가 해결하고자 했던 근본적인 문제는 플랫폼 종속성이었다. C/C++와 같은 언어는 특정 CPU 아키텍처에 맞는 기계 코드를 생성하지만, 자바는 중간 단계를 도입하여 이 문제를 해결했다.

**플랫폼 종속성 문제의 예**
- Windows용으로 컴파일한 프로그램은 Linux에서 실행되지 않고,
    
- ARM용으로 만든 바이너리는 x86 CPU에서는 동작하지 않죠.



## 해결 방법


소스코드 컴파일 과정에 중간 단계를 넣었음 : **[[Java 바이트코드 251019140837|바이트코드]]**


`자바 소스 코드 (.java)` $\rightarrow$ `(컴파일러 javac)` $\rightarrow$ `바이트코드 (.class)` $\rightarrow$
`(자바 가상 머신 JVM)` $\rightarrow$ `각 플랫폼의 실제 기계 코드`

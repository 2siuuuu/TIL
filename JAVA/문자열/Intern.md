## intern된 문자열의 의미 (정확한 정의부터)

**intern된 문자열**이란:

> **[[String Pool]]에 등록되어 관리되는 문자열**을 말한다.

즉,

- JVM이 “이 문자열은 대표 하나만 두고 공유하겠다”고 판단한 문자열
    
- 그 **대표 객체**를 **[[String Pool]]**에 두고 재사용하는 문자열
    

---

## “intern”이라는 말의 의미

### 어원적 의미

- **intern** = _내부에 가두다, 내부 자원으로 편입시키다_
    

Java에서의 의미:

> “이 문자열을 JVM 내부의 String Pool에 편입시켜라”

***
## intern된 문자열의 성질

### 동일성 보장

`String a = "A"; String b = new String("A").intern();  a == b   // true`

- 둘 다 **같은 Pool 객체**를 참조
    

---

### 값 불변성 (immutable)

- String은 원래 불변
    
- intern 여부와 무관하지만,
    
- **공유되기 때문에 불변이 특히 중요**


## 언제 intern을 쓰는가

- **같은 문자열이 대량으로 반복 등장**
    
- **메모리 절약이 중요한 경우**
    
- **`==` 비교가 의미를 가지게 하고 싶을 때**
    

단점:

- Pool 오염 가능
    
- GC 압박 증가
    
- 무분별한 intern은 성능 저하
    

---

## 한 문장 요약

> **intern된 문자열이란, JVM이 대표 하나만 유지하도록 String Pool에 등록해 공유하는 문자열이다.**

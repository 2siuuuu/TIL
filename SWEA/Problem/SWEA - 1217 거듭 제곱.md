$2^2\rightarrow$  제곱이 이루어지는 표현식은 2번 실행되어야 함.

그리고 그걸 재귀함수 형식으로 구현해야 함.

그럼 어떤 함수를 만들고, 매개 변수로 제곱해야 하는 값, 그리고 이 함수가 무한히 호출되는 것을 방지하기 위한 변수를 선언하면 되겠다.

그 값을 각 target, count라고 한다.
만약 내가 $2^3$ 을 구할 것이다! 라면 함수의 매개변수를 `함수(2,3)` 이런 식으로 작성하는 것이다.

```java
public static void main(String[] args) {
	...
	int answer = square(target, count);
	...
}

private static int square(int target, int count) {  
    if (count == 0) {  
        return 1;  
    }  
    return target * square(target, count-1);  
}
```

square 함수는 리턴값으로 곱셈식의 결과를 반환하는데, 곱셈식에는 자기 자신을 호출하는 코드가 포함되어 있다.
여기서 무한 호출을 방지하기 위해 count에서 1을 뺀 값을 매개변수로 보낸다. 이렇게 계속 작아지다가, 0이 되면 1을 반환하게 되는데, 이 때 재귀 호출은 끝이 나며, 재귀 호출이 끝나는 시점에서 반환된 1은, 직전에 자신을 호출시킨 자신의 리턴문의 곱셈식에 포함되며 만약 target = 2라면 `2*1` 이 된다.

`2*1`의 결과는 다시 리턴되어
`2*(2*1)` 이 되고, 이 결과는 다시 리턴 되어
`2*(2*(2*1))` 가 된다. 
count가 3이었다면 결과는 8이 된다.

```java
import java.util.Scanner;  
  
public class Main {  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
        for (int i = 0; i < 10; i++) {  
            int T = sc.nextInt();  
  
            int target = sc.nextInt();  
            int count = sc.nextInt();  
  
            int answer = square(target, count);  
            System.out.println("#"+T+" "+answer);  
  
        }  
        sc.close();  
    }  
  
    private static int square(int target, int count) {  
        if (count == 0) {  
            return 1;  
        }  
        return target * square(target, count-1);  
    }  
  
  
}
```

백준 - 1920 수 찾기

https://www.acmicpc.net/problem/1920

```
5
4 1 5 2 3
5
1 3 7 9 5
```

먼저, N과 N개의 정수.
그리고 M과 M개의 수.

1,3,7,9,5가 4,1,5,2,3에 있느냐를 확인해서 출력하면 됨.
순서대로.

1,3,7,9,5 에서 1은 N개의 정수 집합에 포함됨.
그래서 1
3도 있음.
7과 9는 없으니 0
5는 있으니 1.
그래서 
출력은 다음과 같다.
1
1
0
0
1

두 번째 입력으로 주어지는 수 들을 정렬해야 겠다. 오름차순으로 정렬하면 된다.

```java
    import java.util.*;
    import java.io.*;

    public class Main {
        private static int binary_search(int[] arr, int target, int start, int end) {
            if (start > end) {
                return -1;
            }
            int mid_idx = (start + end) / 2;
            if (arr[mid_idx] == target) {
                return mid_idx;
            } else if (arr[mid_idx] > target) {
                return binary_search(arr, target, start, mid_idx - 1);
            } else {
                return binary_search(arr, target, mid_idx + 1, end);
            }
        }


        public static void main(String[] args) throws IOException {
            BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
            BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
            StringBuilder sb = new StringBuilder();

            int N = Integer.parseInt(br.readLine());
            StringTokenizer st = new StringTokenizer(br.readLine());

            int[] arr = new int[N];
            for (int i = 0; i < N; i++) {
                arr[i] = Integer.parseInt(st.nextToken());
            }
            Arrays.sort(arr);

            int M = Integer.parseInt(br.readLine());
            StringTokenizer st2 = new StringTokenizer(br.readLine());
            for (int i = 0; i < M; i++) {
                int target = Integer.parseInt(st2.nextToken());
                int result = binary_search(arr, target, 0, N-1);
                if(result == -1) {
                    sb.append(0).append("\n");
                } else {
                    sb.append(1).append("\n");
                }
            }



            bw.write(sb.toString());

            bw.flush();
            bw.close();
            br.close();
        }
    }

```

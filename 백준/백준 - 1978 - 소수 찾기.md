백준 - 1978 - 소수 찾기

https://www.acmicpc.net/problem/1978

소수는 1보다 큰 자연수 중 1과 자기 자신만을 약수로 가지는 수

소수의 규칙
2를 제외하고 모두 홀수

그럼 홀수인 것이 정답인가? 아니다. 15는 1,3,5,15의 약수를 가진다.
17처럼 1과 자기 자신 만을 홀수로 가져야 한다.

방법:

2,3,4,5,6,7,8,9로 나눴을 때 모든 경우에서 나머지가 0이 아니면 홀수이다.


실패 
```java
import java.io.*;  
import java.util.StringTokenizer;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //N  
        int N = Integer.parseInt(br.readLine());  
  
        int answer = N;  
        int[] nums = {2,3,4,5,6,7,8,9};  
        StringTokenizer st = new StringTokenizer(br.readLine());  
        for (int i = 0; i < N; i++) {  
            int target = Integer.parseInt(st.nextToken());  
            if (!(target == 2)) {  
                for(int n : nums) {  
                    int a = (target % n) != 0 ? -1 : 0;  
                    answer += a;  
                }  
            }  
        }  
        sb.append(answer);  
  
        //출력  
        bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

위 코드 개선할 점

- target이 1이거나 2이면 무조건 소수임. 그러므로 검사 자체에서 제외하는 코드 넣기.

- 두 번째 for문에서 target이 소수가 아님이 판정될 때마다 정답을 1 감소 시킴. 즉 여러 번 감소 시키는 문제가 있음. break문 필요.


실패
```java
import java.io.*;  
import java.util.StringTokenizer;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //N  
        int N = Integer.parseInt(br.readLine());  
  
        int answer = N;  
        int[] nums = {2,3,4,5,6,7,8,9};  
        StringTokenizer st = new StringTokenizer(br.readLine());  
        for (int i = 0; i < N; i++) {  
            int target = Integer.parseInt(st.nextToken());  
            if (!(target == 2 || target == 1)) {  
                for(int n : nums) {  
                    if (!(target == n)) {  
                        if ((target % n) == 0) {  
                            answer--;  
                            break;  
                        }  
                    }  
                }  
            }  
        }  
        sb.append(answer);  
  
        //출력  
        bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

틀린 이유:

1은 소수가 아닌데, 그 점을 간과하고 있었다. 즉 소수의 정의에 대한 숙지 미숙.

그리고 배열을 미리 선언해서 사용하는 방법은 11을 나누었을 때 떨어지는 수에 대해서 판별하지 못한다. (121) 


수정한 방법:
1, 2인 경우를 먼저 처리하고,
나머지의 경우에는 2부터 자기 자신 직전까지의 수를 모두 나눴을 때 나머지가 0이면 소수가 아닌 것으로 처리하는 방법으로 변경하였다.

결과 : 성공
```java
import java.io.*;  
import java.util.StringTokenizer;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //N  
        int N = Integer.parseInt(br.readLine());  
  
        int answer = N;  
  
        StringTokenizer st = new StringTokenizer(br.readLine());  
        for (int i = 0; i < N; i++) {  
            int target = Integer.parseInt(st.nextToken());  
            if (target == 1) {  
                answer--;  
            }  
            else {  
                if (!(target == 2)) {  
                    for (int j = 2; j < target; j++) {  
                        if ((target % j) == 0) {  
                            answer--;  
                            break;//이걸빼먹었다  
                        }  
                    }  
                }  
            }  
        }  
        sb.append(answer);  
  
        //출력  
        bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

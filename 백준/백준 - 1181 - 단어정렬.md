# 단어입력받기
크기가 50인 배열을 선언하고 그 배열 안에 `ArrayList<String>`을 선언한다

단어 길이가 3이면 
그 단어는 배열의 3번째 인덱스로 보낸다

입력된 단어 길이가 1이면 그 단어는배열의1번째인덱스로보낸다

이 시점에서 길이를 기준으로 오름차순 정렬은 완료된다.
# 중복되는 단어 제거
배열의 인덱스를 돌며
각 인덱스에 저장된 단어들을 검사한다
검사 기준은 똑같은 단어가 있느냐 이다

먼저 배열 전체를 순회해야 하므로 50번 반복하는 for문 선언 (for-1)
첫 번째 순회에서 0번 인덱스의 단어들을 검사한다
검사는 for문으로 하는데, 반복 횟수는 해당 인덱스안의 배열 길이이다
즉 `ArrayList<String>`(List-1) 안에 `ArrayList<String>`(List-2)가 또 있는 것이다.

0번 인덱스의 ArrayList의 길이만큼 반복하는 for문을 연다 (for-2)
그 길이의 의미는 0번 인덱스 공간에 저장된 문자열들의 갯수이다. 그리고 그 문자열들은 길이가 1이다. 왜냐하면 0번 인덱스에 저장되었으니까.
for-2 에서 검사할 건 List-2의 첫 번째 인덱스에 저장된 문자열이 나머지와 같은지 다른지 검사한다. 같은지 다른지 검사하는 기준은 값이다. 

중복되는 단어를 검사하는 코드가 완성되었다.

50개 공간의 크기를 가진 `ArrayList<String>`타입의 리스트 arr의 공간에는 `ArrayList<String>` 타입의 리스트가 저장된다. 그 리스트를 list로 선언했다

작업은 list안에 값이 있을 때에만 실행한다. 값이 없는 경우가 있는가? 있다.
만약 4글자로 된 단어가 없으면 `arr[3]`에는 아무 값도 들어가있지 않을 것이다.
따라서 해당 공간은 그냥 지나친다.

중복 제거의 로직은 다음과 같다.
- list의 크기 만큼 반복하는 for문을 연다
	- list의 첫 번째 공간의 값 word를 사용한다
- 다시 list의 크기 만큼 반복하는 for문을 연다
	- 두 번째로 연 for문에서는 list의 첫 번째 공간의 값 s를 사용한다.
- word와 s가 같으면 count에 1을 더한다 : 이 행위는 똑같은 단어의 갯수를 세는 행위를 구현한 것이다.
word는 s1,s2,s3과 값 비교를 하게 된다. 여기서, word == s1이기 때문에, 
count는 무조건 1 상승하게 된다. 만약 똑같은 값이 두 개 이상이라면 count는 2 이상이어야 한다.
그러므로 이 상황에서 count가 1을 초과한다면 똑같은 값이 두 개 이상이라는 의미이므로 똑같은 값을 하나만 남기고 전부 제거해야 한다.
그 로직은 다음과 같이 구현했다.
예를 들어 list에 저장된 단어가 abc,abc,apple 이라고 하자. 그럼 count는 2이다.
abc는 하나만 남겨야 한다. 제거하기 위해 반복문을 연다. 반복 횟수는 count-1이다.
1번만 반복을 하게 되며, 실행문에서는 list에서 abc를 한 번 제거한다.

이 과정이 끝나면 해당 list에는 전부 다르지만 단어 길이는 동일한 문자열들만 남았을 것이다. 이제 이 단어들을 사전 순으로 정렬한다.

# 사전순으로 배치
정렬에는 `Collections.sort()`를 사용한다.

정렬이 마치면

`arr[1]`에 저장된 list에 대해 동일한 작업을 수행한다. 이 작업을 반복하면,
arr에는 사전 순으로 정렬되었고 중복된 단어가 없는 문자열들이 저장된 `ArrayList<String>`타입의 배열이 각 공간에 저장되게 된다. 그리고 arr의 인덱스 번호의 의미는 다음과 같다
0 - 길이가 1인 문자열들이 저장된 `ArrayList<String>`타입 배열이 저장된 arr의 배열 공간의 인덱스 번호

# 출력
위 과정이 모두 끝나면 이제 출력하는 일만 남는다.

출력은 arr의 첫 번째 인덱스부터 차례대로 값을 꺼내어 출력하면 된다.
출력은 stringbuilder 클래스의 append메서드를 활용한다.


# 1차 시도 - 실패
```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
  
        //크기가 50인 ArrayList 선언  
        ArrayList<String>[] arr = new ArrayList[50];  
        //초기화  
        for (int i = 0; i < 50; i++) {  
            arr[i] = new ArrayList<>();  
        }  
  
        //N,단어 입력  
        int N = Integer.parseInt(br.readLine());  
        for (int i = 0; i < N; i++) {  
            String word = br.readLine();  
            arr[word.length()-1].add(word);  
        }  
  
        //작업1 중복되는 단어 제거  
        for (ArrayList<String> list : arr) { //for1  
            if (!list.isEmpty()) {  
                //중복 제거  
                for (String word : list) {//for2  
                    int count = 0;  
                    for (String s : list) {//for3  
                        if (word.equals(s)) {  
                            count++;  
                        }  
                    }  
                    //만약 count가 1 이상이면 2개 이상 있다는 의미 - 하나만 남을 때 까지 전부 remove                    if (count > 1) {  
                        for (int i = 0; i < count-1; i++) {  
                            list.remove(word);  
                        }  
                    }  
                }  
                //사전 순 정렬  
                Collections.sort(list);  
  
            }  
        }  
  
        //출력  
        for (ArrayList<String> list : arr) {  
            if (!list.isEmpty()) {  
                for (String word : list) {  
                    sb.append(word).append('\n');  
                }  
            }  
        }  
  
  
        //출력  
        bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

## 원인

원인은 작업1의 for2에서 발생했다.
다음은 AI의 답변 :
작성하신 코드에서 문제는 `for2`와 그 내부의 `remove` 로직 사이에서 발생합니다.

- **`for (String word : list)`**: 이 구문은 내부적으로 `Iterator`를 생성하여 리스트를 순회합니다.
    
- **`list.remove(word)`**: 반복문이 아직 끝나지 않았는데 리스트의 요소를 지워버립니다.
    
- **충돌**: `Iterator`는 다음 요소를 가져오려다 리스트가 변경된 것을 감지하고 "동시 수정 오류"를 던집니다.

AI는 해결 방법으로 Set 자료구조를 사용할 것을 추천했다.
그 이유는 내가 작성한 로직은 오류를 잡는다고 해도 성능상으로 비효율적이라고 한다. 


Set 자료구조를 사용해서 문제를 해결했다. 


# 2차 시도 - 성공

```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
  
        //크기가 50인 ArrayList 선언  
        ArrayList<String>[] arr = new ArrayList[50];  
        //초기화  
        for (int i = 0; i < 50; i++) {  
            arr[i] = new ArrayList<>();  
        }  
  
        //N,단어 입력  
        int N = Integer.parseInt(br.readLine());  
        for (int i = 0; i < N; i++) {  
            String word = br.readLine();  
            arr[word.length()-1].add(word);  
        }  
  
        //작업1 중복되는 단어 제거  
        for (ArrayList<String> list : arr) { //for1  
            if (!list.isEmpty()) {  
                //중복 제거  
                Set<String> uniqueSet = new HashSet<>(list);  
  
                //중복 제거된 버전을 list에 채움  
                list.clear();  
                list.addAll(uniqueSet);  
  
                //사전 순 정렬  
                Collections.sort(list);  
  
            }  
        }  
  
        //출력  
        for (ArrayList<String> list : arr) {  
            if (!list.isEmpty()) {  
                for (String word : list) {  
                    sb.append(word).append('\n');  
                }  
            }  
        }  
  
  
        //출력  
        bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

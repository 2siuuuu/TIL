# 문제 이해
```
10
6 3 2 10 10 10 -10 -10 7 3
8
10 9 -5 2 3 4 5 -10
```

1번째 줄과 2번째 줄
상근이가 가지고 있는 카드. 그리고 그 카드에 적힌 숫자들.

3,4번째 줄
상근이가 가지고 있는지 확인해야 할 카드 번호.
예를 들어, 10은 상근이가 3개 가지고 있다. 그러므로 출력은 3이 포함될 것이다
9는 없으니 0으로 출력될 것이다.


# 아이디어

```
값을 찾았다면 그 target의 갯수를 1증가 시키고 해당 배열의 위치에 null 삽입. 그리고  이분 탐색을 한 번 더 실행.
한 번 더 실행 후에 또 찾는다? 또 해. 못 찾으면 그때 종료하고 다른 target으로 넘어가.
```

원래 위 처럼 풀려고 했지만 도저히 풀리지 않았고 방법이 너무 복잡해서, 해결책을 검색해보니 upperBound와 lowerBound 메서드를 구현해서 푼다고 하더라.

위 2개 메서드로 문제를 푸는 아이디어는 다음과 같다:

일단, 리스트에 아래와 같이 정렬된 요소가 있을 때, Target은 3이라고 하자.
![](https://i.imgur.com/zncYxEJ.png)

이 때 lowerBound(3)은 2을 리턴하고
upperBound(3)은 4를 리턴한다.
![](https://i.imgur.com/4QH0brq.png)

$4-2 = 2$ 이므로 Target의 갯수는 2이다.

upperBound와 lowerBound 둘 다 이분탐색 알고리즘을 응용한 것이다.


# 코드
```java
import java.util.*;
import java.io.*;

public class Main {
    public static int[] cards;

    public static int lowerBound(int target) {
        int left = 0;
        int right = cards.length; 

        while (left < right) {
            int mid = (left + right) / 2;

            if (cards[mid] >= target) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }

        return left;
    }

    public static int upperBound(int target) {
        int left = 0;
        int right = cards.length;

        while (left < right) {
            int mid = (left + right) / 2;

            if (cards[mid] > target) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }

        return left;
    }


    public static void main(String[] args) throws IOException {
        List<Integer> list = new ArrayList<>();
        list.add(1);
        list.add(2);
        list.add(3);

        int dd = list.get(1);



        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        StringBuilder sb = new StringBuilder();

        int N = Integer.parseInt(br.readLine());
        StringTokenizer st = new StringTokenizer(br.readLine());

        int[] arrays = new int[N];
        for (int i = 0; i < N; i++) {
            arrays[i] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(arrays);
        cards = arrays;

        int M = Integer.parseInt(br.readLine());
        StringTokenizer st2 = new StringTokenizer(br.readLine());
        for (int i = 0; i < M; i++) {
            int target = Integer.parseInt(st2.nextToken());

            int targetCount = upperBound(target) - lowerBound(target);
            sb.append(targetCount).append(" ");
        }



        bw.write(sb.toString());

        bw.flush();
        bw.close();
        br.close();
    }
}
```

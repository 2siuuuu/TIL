```
import java.util.Arrays;  
import java.util.Scanner;  
  
public class Main {  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
        int dice1 = sc.nextInt();  
        int dice2 = sc.nextInt();  
        int dice3 = sc.nextInt();  
  
        int[] arr = {dice1,dice2,dice3};  
        Arrays.sort(arr);  
  
        if(dice1 == dice2 && dice2 == dice3) {  
            //조건1  
            System.out.println(10000+(dice1*1000));  
        } else if (dice1 == dice2 || dice2 == dice3) { // 조건 2에서 같은 눈을 판별하는 방법 : dice2는 두 조건 식에 속하고, 어느 식이든 하나만 맞기만 하면 dice2는 1또는3과 무조건 같으므로 dice2는 같은 눈이다.  
            //조건2  
            System.out.println(1000+(dice2*100));  
        } else {  
            //조건3  
            System.out.println(arr[arr.length - 1]*100);  
        }  
    }  
}
```

틀린 이유를 알아내었다.
왜냐하면 조건식에 정렬된 배열을 사용하지 않았기 때문이다. 사용해야 했지만 수정하는 것을 잊은 것이다.

즉 실제 코드에서, 조건식에 놓인 것들은 정렬되지 않은 변수들이기 때문에 내가 예상했던 결과를 내지 못하는 것이다.

내가 세운 로직을 실제 코드에 반영하지 않은 것이다. 이제 로직을 코드로 옮겨서 성공한다면, 다음의 주의사항을 트러블슈팅 노트에 기록할 것이다.

성공한 코드:
```java
import java.util.Arrays;  
import java.util.Scanner;  
  
public class Main {  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
        int dice1 = sc.nextInt();  
        int dice2 = sc.nextInt();  
        int dice3 = sc.nextInt();  
  
        int[] arr = {dice1,dice2,dice3};  
        Arrays.sort(arr);  
  
        if(arr[0] == arr[1] && arr[1] == arr[arr.length - 1]) {  
            //조건1  
            System.out.println(10000+(arr[0]*1000));  
        } else if (arr[0] == arr[1] || arr[1] == arr[arr.length - 1]) { // 조건 2에서 같은 눈을 판별하는 방법 : dice2는 두 조건 식에 속하고, 어느 식이든 하나만 맞기만 하면 dice2는 1또는3과 무조건 같으므로 dice2는 같은 눈이다.  
            //조건2  
            System.out.println(1000+(arr[1]*100));  
        } else {  
            //조건3  
            System.out.println(arr[arr.length - 1]*100);  
        }  
    }  
}
```

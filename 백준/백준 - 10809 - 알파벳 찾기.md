백준 - 10809 - 알파벳 찾기

https://www.acmicpc.net/problem/10809

입력되는 문자열은 소문자로만 이루어진 문자열이다.

알파벳은 a~z 까지 존재한다. 총 26개 이다.

26개의 칸으로 이루어진 배열을 생각해보자.
각 공간의 주인은 a부터 z까지 정해져 있다.
이 배열을 A라고 하자.

이제 입력되는 문자열을 생각해보자.
문자열의 첫 번째 알파벳을 선택한다. 그 알파벳은 A의 공간 중 하나에 무조건 포함될 수 있다. 포함 된다면, 그 공간을 선택한다. <-(이 행위를 A 행위라고 하자)

선택한 공간에 어떤 값을 넣어야 하는지 생각해야 한다.
선택한 알파벳은 입력된 문자열의 어느 위치에 존재하는가?
문자열을 배열로 만든다면 각 알파벳은 배열의 처음부터 마지막까지 하나씩 들어갈 수 있다. 그 배열을 B라고 하자.
배열 B의 0번 인덱스에 해당하는 값은 문자열의 첫 번째 알파벳이다.
그러므로 선택한 공간에 0을 넣으면 된다.
<- ( 이 행위를 B 행위라고 하자)

이런 식으로 문자열의 마지막 알파벳 까지 연산을 하면 된다.


a,b를 0,1로 인코딩할 수 있다면?
'a' - 97 = 0
'b' - 97 = 1.  가능!


```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //단어 s 입력  
        String S = br.readLine();  
  
        //알파벳 바구니 만들기  
        int[] alphabets = new int[26];  
        Arrays.fill(alphabets, -1);  
  
  
        for (int x = 0; x < S.length(); x++) {  
            // 바구니에 채우기 전에 이미 그 위치에 입력되었으면 pass            if (alphabets[S.charAt(x) - 'a'] != -1) continue;  
            // 바구니에 채운다  
            alphabets[S.charAt(x) - 'a'] = x;  
        }  
  
        // 결과 출력  
        for (int i = 0; i < 26; i++) {  
            sb.append(alphabets[i]).append(' ');  
        }  
  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

A 행위를 구현한 방법은 아래와 같다
`alphabets[S.charAt(x) - 'a']`

B 행위를 구현한 방법은 아래와 같다
`alphabets[S.charAt(x) - 'a'] = x`

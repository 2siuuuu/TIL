
https://www.acmicpc.net/problem/2566


81개의 격자 판의 위치에 각각 어떤 수가 주어질 지 알 순 없지만 
값의 범위는 0~99까지이다.

그래서 나는 우선 9x9 크기의 2차원 배열을 만든 후에, 일단 배열에 값을 모두 채워 넣는다.

이후 검색 과정을 거쳐 답을 찾아낸다.

검색은 총 99번 이루어진다.
먼저 검색 대상은 99이고, 격자의 처음부터 마지막까지 99와 같은 값을 찾는다.
찾으면 정답인 것이고 못 찾는다면 최댓값은 99가 아니라는 뜻이므로, 99에서 1을 감소시켜 검색을 처음부터 다시 수행한다.
이 과정을 99번 반복하는 것이며, 최종적으로 마지막 검색 과정에선 검색 대상이 0이고 0과 같은 값을 찾는다.

시간 복잡도는 
한 변을 N이라고 했을 때 N²
99번 반복 -> M x N²

`O(MN²)`

```java
import java.io.*;  
import java.util.StringTokenizer;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //격자판 입력 시작  
        int[][] map = new int[9][9];  
        for (int i = 0; i < 9 ; i++) {  
            StringTokenizer st = new StringTokenizer(br.readLine());  
            for (int j = 0; j < 9; j++) {  
                map[i][j] = Integer.parseInt(st.nextToken());  
            }  
        }  
  
        // 검색  
        sb = search(map,sb);  
  
  
        //출력  
        bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
    public static StringBuilder search(int[][] map, StringBuilder sb) {  
  
        for (int target = 99; target >= 0 ; target--) {  
            for (int j = 0; j < 9; j++) {  
                for (int k = 0; k < 9; k++) {  
                    if (map[j][k] == target) {  
                        sb.append(target).append('\n').append(j+1).append(' ').append(k+1);  
                        return sb;  
                    }  
                }  
            }  
        }  
        return sb;  
    }  
  
}
```

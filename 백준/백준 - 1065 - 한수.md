백준 - 1065 - 한수

https://www.acmicpc.net/problem/1065


# 문제이해
일단 이걸 풀려면 등차수열이 뭔지 알아야 한다
등차수열은 이런 것이다 
1 3 5 7. 이 수열의 값들의 차이가 +2씩 일정하다. 그래서 이 수열은 등차수열이다.

그럼 한수란, 135를 말한다. 135를 수열로 보면 1 3 5이다. +2씩 일정하게 차이가 나니까 
135는 한수이다.

N이 110이라고 해보자. 
1부터 10까지 10개의 한수가 있다.
10은 1 0 이라는 수열로 나타낼 수 있고 두 수가 -1의 일정한 차이를 보인다
11부터 99까지는 모두 한수이다. 그러므로 1~99까지는 한수가 99개 있다.
100은? 이것을 수열로 나타내면 차이가 일정하지 않다.
100 ~ 110까지는 수열의 차이가 전혀 일정하지 않다. 따라서 N=110일 때, 답은 99이다.

# 아이디어

N이 100 == 반복의 횟수

1~99까지는 한수이니까 N이 99보다 작거나 같으면 답은 N이다

100 이상이라면 아래의 아이디어를 적용해본다

N이 100 이상일 때,
현재 검사하는 숫자가 3자리든 4자리든 그 수는 무조건 한수일 것이라고 가정한다.
그렇다면 이 숫자가 3자리 숫자라고 가정했을 때 a자리,b자리,c자리 이면
b-a의 값은 수열의 차이에 해당하는 값이고, 이걸 x라고 했을 때
a + x = b
b + x = c 여야만 한다.
하나라도 틀리다면 그 수는 한수가 아닌 것이다.

예를 들어 N이 200이라서 현재 100을 검사 중이라고 치자

1 0 0 
a b c

b-a = -1 이므로 x = -1

a + x = b
1 - 1 = 0 <- 이건 참

b + x = c
0 - 1 = -1 <- c는 0인데 -1이 나왔으므로 거짓

100은 한수가 아님

# 코드
```java
import java.util.*;  
import java.io.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        int N = Integer.parseInt(br.readLine());  
        int answer = N;  
        if (N <= 99) sb.append(answer);  
        else {  
            for (int i = 100; i <= N; i++) {  
                int[] arr = new int[4];  
                int top = 0;  
                int length = 0;  
                int t = i;  
                while (t > 0) {  
                    arr[top++] = t%10;  
                    t /= 10;  
                    length++;  
                }  
                int x = arr[0]-arr[1];  
  
                for (int j = 0; j < length-1; j++){  
                    if (arr[j] - arr[j + 1] != x) {  
                        answer--;  
                        break;  
                    }  
                }  
            }  
            sb.append(answer);  
        }  
  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
}
```

https://www.acmicpc.net/problem/1316

이 문제는 단어 속 문자가 달라지는 지점의 순간에, 지금 달라진 이 단어가 전에도 나왔는지 판별하면 되는 문제이다.

이 문제는 출석부, 스타터, target을 만들어 놓고 검사를 진행하였다.

출석부는 boolean으로 된 배열이고 알파벳의 갯수만큼의 크기를 가진다.
스타터는 예를 들어, 'aaabbbccc'단어에서 스타터는 a이다. 
target은 만약  현재 'aaa[b]bbccc'를 검사중이라면 b는 target이다.

단어를 입력받으면 검사가 시작된다.
만약 스타터와 target이 같으면 streak인 것으로 보고 다음 검사로 넘어간다.
다음 검사에서 target은 단어의 다음 문자이다.

만약 스타터와 target이 다르다면, target을 스타터로 만든다.
그리고 새로운 스타터가 과거에 존재했는지 출석부를 확인한다.
출석부에 존재했다면 이 단어는 그룹 단어가 아니므로 즉시 검사를 종료한다.

존재하지 않는다면 새로운 스타터를 출석 처리 하고 다음 검사를 진행한다.

검사가 모두 무사히 완료되면 해당 단어는 그룹 단어인 것이고,
중간에 검사가 종료된다면 해당 단어는 그룹 단어가 아닌 것이다.


# 1차 시도 - 성공
```java
import java.io.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        // N입력  
        int N = Integer.parseInt(br.readLine());  
  
        // 검사  
        int answer = 0;  
        for (int i = 0; i < N; i++) {  
            String word = br.readLine();  
            boolean[] attendance = new boolean[26];  
            char starter = word.charAt(0);  
            attendance[starter - 'a'] = true;  
  
            for (int j = 1; j < word.length(); j++) {  
                char target = word.charAt(j);  
                if (starter == target) {  
                    //같다 - streak                    
                    continue;  
                }  
                else {  
                    // 다르다 - streak broken                    
                    starter = target;  
                    if (attendance[starter - 'a']) {  
                        //그룹단어가 아님  
                        answer--;  
                        break;  
                    }  
                    else {  
                        attendance[starter - 'a'] = true;  
                    }  
  
                }  
  
            }  
            //검사를 무사히 마치면 그룹 단어인 것으로 가정  
            answer++;  
        }  
        //출력  
        sb.append(answer);  
  
        //출력  
        bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

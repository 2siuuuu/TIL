정수 123을 
1과 2와 3으로 차례대로 분리하고 각각을 정수로써 이용할 수 있다.

기본 아이디어 : 

1. 나머지 연산
target 숫자를 10에 대해 나머지 연산한다.
123 % 10 = 3이 추출된다.

2. 나눗셈
이후 123 / 10 -> 12

3. 위 과정을 반복
target 수가 0보다 작아질 때 까지 반복한다.


정리하면 1의 자리 수 부터 추출하여 사용할 수 있는 방법이다.



```java
int num = 123;
while (n > 0) {
	res += (n % 10);
	n /= 10;
}
```

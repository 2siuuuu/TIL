최대 공약수 : GCD ( Greatest Common Divisor )
어떤 두 수 a,b가 있다 (a>b)
a % b의 값을 r이라 하자.

이 때 a,b의 최대 공약수는 b,r의 최대공약수와 같다.

다음은 이를 구현한 코드이다.

```java
int gcd = getGCD(num1, num2);



getGCD(int a, int b) {  
    return b == 0 ? a : getGCD(b, a % b);  
}
```

a % b == r


# 0의 약수
https://gemini.google.com/share/b23f81b5c302
어떤 수 $d$가 $n$의 **약수**가 되려면, $n = d \times k$ (단, $k$는 정수)를 만족해야 한다.

0의 약수를 구해야 하므로 $n = 0$ 
만약 1이 0의 약수인지 확인하려면 :
$d = 1$ 
$0 = 1 \times k$
위 식에서 $1 \times k$ 가 0이 될 수 있도록 하는 정수 k를 찾으면 됨.

d가 어떤 정수든지 간에 k가 0이라면 위 식은 성립하므로 0은 모든 수의 약수가 됨.


# 최소공배수를 구하는 공식
Least Common Multiple ( LCM )

어떤 두 자연수 $a, b$가 있을 때 다음 식이 항상 성립합니다:

$$L = \frac{a \times b}{G}$$

_(여기서 $L$은 최소공배수, $G$는 최대공약수입니다.)_

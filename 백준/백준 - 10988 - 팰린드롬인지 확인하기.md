백준 - 10988 - 팰린드롬인지 확인하기

https://www.acmicpc.net/problem/10988

팰린드롬이라면
aba
이거나
abba이다.

팰린드롬인지 판별하는 방법은 길이가 홀수이냐, 짝수이냐에 따라 다르다.

**홀수**:
가운데 글자를 제외하고, 양쪽 끝에서부터 각각 한 글자씩 검사한다. 
예를 들어,
`abcba`

c를 제외하고
가장 왼쪽 a와, 가장 오른쪽 a를 검사 - 검사 1회
왼쪽 b와 오른쪽 b를 검사 - 검사 2회

검사 시 서로 다른 문자라면 팰린드롬이 아니다.

**짝수**:
양쪽 끝에서부터 각각 한 글자씩 검사한다.
`abba`

왼쪽 a와, 오른쪽 a를 검사 - 검사 1회
왼쪽 b와 오른쪽 b를 검사 - 검사 2회

검사 시 서로 다른 문자라면 팰린드롬이 아니다.

**검사의 횟수**
검사는 몇 번할 것인가? 검사 대상인 글자의 길이에 따라 다르다.

**홀수 길이 단어의 검사 횟수**
( ( 글자 길이 +1 ) / 2 ) -1

**짝수 길이 단어의 검사 횟수**



```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        StringBuilder sb = new StringBuilder();

        //단어 입력 받기
        String word =  br.readLine();

        // 홀수OR짝수 = word.길이를 2로 나눈 나머지가 0이면 짝수 1이면 홀수이니 true이면 1, false이면 0을 저장
        boolean isOdd = (word.length() % 2) != 0;

        //검사 횟수 설정
        // 홀수이면  ((size+1)/2)-1 의 결과를 저장, 짝수이면 (size+1)//2
        int count = isOdd ? ((word.length()+1)/2)-1 : (word.length()+1)/2 ;

        //검사
        int result = 1;
        for (int i=0; i<count; i++) {
            if (!(word.charAt(i) == word.charAt((word.length()-1)-i))) {
                result = 0;
                break;
            }
        }

        sb.append(result);

        //출력
        bw.write(sb.toString());
        bw.flush();
        bw.close();
        br.close();
    }

}
```

 백준 - 11866 - 요세푸스 문제 0
 
 https://www.acmicpc.net/problem/11866

# 문제 이해:
5명이 있다
`[1][2][3][4][5]`

3번째 놈을 제거할겨
`[1][2][3][4][5]`
`[ ][ ][↑][ ][ ]`

제거 후 모습
`[1][2][4][5]`
하지만 제거한 후에도 3번째 놈을 가리키던 포인터는 남아있다고 생각해라
`[1][2][ ][4][5]`
`[ ][ ][↑][ ][ ]`

이 상태에서 그 다음 3번째 놈을 제거
`[1][2][ ][4][5]`
`[↑][ ][ ][ ][ ]`

제거 후 모습
`[ ][2][ ][4][5]`
`[↑][ ][ ][ ][ ]`

이걸 아무도 안 남을 때 까지 반복함.
아무도 안 남았을 때, 제거된 놈들을 순서대로 나열하면 그게 요세푸스 순열이다.

`3, 6, 2, 7, 5, 1, 4`



# 핵심 아이디어

중간에서 빼는 건 불가능 하니,
먼저 다음 과정을 K-1번 반복한다.
1. poll한다
2. poll한 요소를 다시 offer한다.

위 과정을 K-1번 반복한 후, poll한다면 그 요소는 해당 테스트 케이스의 요세푸스 순열의 첫 번째 요소이다.

# 코드
```java
import java.util.*;  
import java.io.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        Queue<Integer> q = new LinkedList<>();  
  
        StringTokenizer st = new StringTokenizer(br.readLine());  
        int N = Integer.parseInt(st.nextToken());  
        int K = Integer.parseInt(st.nextToken());  
  
        for (int i = 0; i < N ; i++) {  
            q.offer(i+1);  
        }  
  
        sb.append('<');  
        while(!(q.isEmpty())) {  
            for (int i = 0; i < K-1; i++) {  
                q.offer(q.poll());  
            }  
            if (!(q.isEmpty())) {  
                sb.append(q.poll());  
            }  
            if (q.isEmpty()) {  
                sb.append('>');  
                break;  
            } else {  
                sb.append(", ");  
            }  
        }  
  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
}
```

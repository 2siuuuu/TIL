https://www.acmicpc.net/problem/10807



첫째 줄 - 정수의 개수 N(1 ≤ N ≤ 100)
둘째 줄 - 주어지는 정수
셋째 줄 - 찾으려고 하는 정수 v 

주어지는 정수의 범위는 -100 ~ 100

나는 주어지는 정수 중에 v가 몇 개인지 숫자로 출력하는 프로그램을 짜면 된다.


처리 과정
1. 둘째 줄의 입력을 전부 문자열 데이터로 받아서 스플릿하여 배열의 요소로서 저장한다.
2. v와 배열의 첫 번째 요소부터 마지막 요소까지 하나씩 대조하여 v와 일치하는 것의 개수를 센다.
3. 개수를 저장하는 변수에, 일치하는 요소의 총 개수를 담아서 출력한다.



알고리즘 설계

**1번을 해결하는 로직을 설계**

정수의 개수 N을 입력받아서 변수에 저장한다.

둘째 줄에 입력되는 주어지는 정수를 어딘가에 저장해야 한다.
입력받는다면 이런 형태일 것이다:
1 2 3 4 5 6

그럼 나는 이 것을 배열에다 저장할 수 있다.
readLine()으로 읽어온 한 줄의 숫자로 된 문자열 데이터를 StringTokenizer 객체를 생성하기 위한 생성자의 파라미터로 전달하여 st라는 StringTokenizer 객체를 생성한다.[^1]

그 문자열 데이터는 str이고, st는 str의 문자열을 공백(기본 구분자)을 기준으로 분해할 준비를 하는 객체이다.


이 객체의 클래스에서 지원하는 메서드인 countTokens()를 활용하여 배열을 만드는 과정을 시작할 수 있다.[^2]

countTokens()을 활용해 토큰의 개수를 담은 int형 변수 count를 초기화 하고
String 타입의 배열 arr을 생성하며, 그 배열의 크기를 토큰의 개수만큼 생성한다.
그리고 for문을 돌려서 배열의 첫 번째 공간부터 마지막 공간까지 st에 저장된 데이터를 채워넣어야 한다. 반복의 수는 토큰의 개수만큼.

이 시점에서 arr에는 st의 데이터가 스플릿되어 배열로 저장되어 있다.


**2번 로직 설계**

배열의 첫 번째 요소와 V가 같은지 다른지 대조하여 같은 것의 개수를 세어야 한다.

대조를 위해서 배열의 1~마지막 번째 요소의 값을 조회해야 하므로 반복문을 사용해야 한다.
for문이 적절하고, 반복 횟수는 배열의 크기 만큼이다.

한 번의 반복 안에서 실행되어야 하는 로직은 다음과 같다
1. 배열의 첫 번째 요소를 조회한다.
2. V값을 그 요소와 == 비교한다.
3. true이면 일치한다는 뜻이다. 일치하는 것의 수를 저장하는 int형 변수 answer를 선언하고 answer++ 한다.
4. false이면 일치하지 않으므로 배열의 다음 요소와 V의 비교가 이루어져야 한다. 반복을 끝내고 다음 반복을 진행해야 한다.

**3번 로직 설계**
2번 로직이 끝나면 answer에 답이 저장되었을 것이다.
BufferedWriter 의 객체를 사용해 답을 출력하면 된다.


첫 번째 시도:
```
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        // N을 입력받음  
        int N = Integer.parseInt(br.readLine());  
        //둘째 줄 입력 받음  
        StringTokenizer st = new StringTokenizer(br.readLine());  
        //셋째 줄 입력 받음  
        int V = Integer.parseInt(br.readLine());  
  
        int tokenCount = st.countTokens(); // 토큰의 총 개수 파악 (3개)  
        String[] arr = new String[tokenCount]; // 개수만큼 배열 생성  
  
        for (int i = 0; i < tokenCount; i++) {  
            arr[i] = st.nextToken(); // 배열의 각 인덱스에 토큰 저장  
        }  
  
        //2번째 공정  
        int answer = 0;  
        for (int i = 0; i < tokenCount; i++) {  
            if (Integer.parseInt(arr[i]) == V) answer++;  
  
        }  
  
        // 3번째 공정  
        bw.write(answer);  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
}
```

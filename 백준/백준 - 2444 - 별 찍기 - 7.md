백준 - 2444 - 별 찍기 - 7

https://www.acmicpc.net/problem/2444

입력이 3이면
첫째 줄부터 2x3-1번째 줄 까지 차례대로 별을 출력해야 한다.

N : 3일 때
2x3-1 : 5

N : 4일 때
7

N : 5일 때
9

N : 6일 때
11

별의 높이는 1,3,5,7,9,...와 같은 홀수이다.

별의 모양은 다이아몬드이다.
N이 5일 때, 별은 9줄로 구성된다.
이때, 가운데는 다섯번째 줄이다.
가운데는 다이아몬드 모양에서 별이 최댓값을 가지는 부분이다.
2 x N - 1 == 한 줄에 가지는 별 개수의 최댓값 == 별의 층수
이 특징을 살려서 코딩하면 될 것 같다.


```java
import java.io.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //N  
        int N =  Integer.parseInt(br.readLine());  
  
        for (int i = 0 ; i < N ; i++) {  
            //이 for문 한 번 반복 시 한 줄 완성  
            //모두 반복 시 N번 째 줄 까지 완성.  
            //공백  
            for (int j = 0; j < N-1-i; j++) {  
                sb.append(' ');  
            }  
            //별  
            for (int j = 0; j < (2*i)+1; j++) {  
                sb.append('*');  
            }  
  
            sb.append('\n');  
        }  
  
        //N번째 줄 이후 출력  
        for (int i = 1 ; i < N ; i++) {  
            //이 for문 한 번 반복 시 한 줄 완성  
            //모두 반복 시 2N-1번 째 줄 까지 완성.  
            //공백  
            for (int j = 0; j < i; j++) {  
                sb.append(' ');  
            }  
            //별  
            for (int j = 0; j < (2*N)-1-(2*i); j++) {  
                sb.append('*');  
            }  
  
            sb.append('\n');  
        }  
  
        //출력  
        bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

백준 - 2869 - 달팽이는 올라가고 싶다

https://www.acmicpc.net/problem/2869

이 문제는 처음엔 반복문으로 풀리면 되겠다고 생각하여 쉽게 풀리겠거니 생각했다. 하지만 단순 반복문으로는 250ms 안에 풀 수가 없었다.

그래서 gemini에게 힌트를 좀 얻었다.

이 문제는 반복문으로 풀 수 없지만 수학 공식을 찾아내어 풀어야 하는 문제였다.

결론적으로 아래 식을 코드에 적용하면 풀 수 있는 문제였다.

$$(A−B)(x−1)+A≥V$$
중요한 것은 이 식을 내가 이해했느냐이다. 물론 처음엔 이해가 되지 않았다. 대충 무슨 느낌인지는 이해했으나 이제 나는 그런 식으로 넘어가면 안 되기 때문에 파고들었다.

우선 문제의 상황을 이해하는 것 부터 시작해야 했다.

달팽이는 낮에만 A 만큼 움직일 수 있고 밤에는 B만큼 떨어진다.

일단 막대기 정상에 오르기만 한다면 더 이상 미끄러지지는 않는다. (나무 막대는 원기둥 모양인 것 같다.)

매우 간단하지만 이 것을 수학 공식으로 변환하기란 처음부터 쉽지는 않았다.

우선 달팽이는 하루동안 총 A-B만큼 움직일 수 있다. 이건 당연하다.
그런데 만약 그 하루동안 움직여서 꼭대기에 도달했다면?
두 가지 상황이 있을 것이다.
1. 낮에 A만큼 움직였고 밤에 B만큼 줄었는데 꼭대기에 도달했다.
2. 낮에 A만큼 움직였는데 꼭대기에 도달했다.
결과는 같지만 문제 조건에 의하면 꼭대기에 도달하는 즉시 달팽이는 미끄러지지 않는다고 한다.

그러므로 꼭대기에 도달한 그 날은 달팽이는 A만큼만 움직이면 되는 것이다.

그럼 마지막 날을 제외한 나머지 날은? 무조건 (A-B)만큼만 움직일 수 밖에 없다.

만약 달팽이가 꼭대기까지 가기 위해 걸리는 총 일 수를 x라고 하면
x에는 A만 움직이면 되는 마지막 날에 해당하는 일 수와 나머지 일 수가 포함되어 있다. 이들은 계산방식이 다르다.
나머지 날은 (A-B)만큼 움직여야 하고, 마지막 날은 A만 움직이기 때문이다. 그래서
(A-B)와 A로 나누어야 하는데, 마지막 날을 제외한 나머지 날은 마지막 날이 되기 전 까지는 반복되어야 한다.
그러니까 3일 동안 올라가서 정상을 찍었다고 가정하면 2일동안 (A-B) 만큼 움직이고 마지막 1일은 A만큼 움직이면 되는데,
이는 (A-B)+(A-B)+A와 같다. 이를 줄이면 (A-B)x2+A이고
사실상 2(A-B) + 1A 라고 할 수 있다.

그래서 식은 (A-B)(x-1) + A가 된다. 
(x-1)이 된 이유는 총 일 수에서 마지막 날을 따로 뺐기 때문이다.

그럼 (A-B)(x-1) + A 이 식 자체는 달팽이가 x일 만큼 올라갔을 때 구해지는 총 거리가 된다. 이 거리는 V이거나 V를 초과할 수 밖에 없다. 
따라서 (A-B)(x-1) + A ≥ V 가 되는 것이다.

나는 x를 구해야 하므로 이 식을 x에 대한 식으로 정리하면
 $x = \frac{V-B}{A-B}$​  이다.

즉 나는 위 식을 그대로 코드에 적용하면 답을 구할 수 있다.

그런데 이 식의 결과가 정수로 깔끔하게 떨어지면 좋지만 소수로 나올 경우가 있다.

예를 들어 4분의 5가 x로 도출되었다고 하면 이는 1.25이다.
1일 하고도 0.25일이 더 필요하다는 의미이다.
그런데 0.25일은 달팽이에게 새로운 하루의 낮 시간에 해당할 것이고 그 시간에 달팽이는 막대의 꼭대기에 도달할 것이다.

문제에서는 정답을 소수점으로 출력하라는 지시가 없다. 그러므로 정수 형태로 출력해야 할 것이다.

그렇다면 0.25일을 무시할 수 없다. 0.25일에 해당하는 시간을 하루가 더 걸린 것이라고 봐야 하므로 +1일 해줘야 한다.
즉 x가 소수점의 형태로 나오면, 올림해줘야 한다.


```java
import java.io.BufferedReader;  
import java.io.BufferedWriter;  
import java.io.IOException;  
import java.io.InputStreamReader;  
import java.io.OutputStreamWriter;  
import java.util.StringTokenizer;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        StringTokenizer st = new StringTokenizer(br.readLine());  
        int A = Integer.parseInt(st.nextToken());  
        int B = Integer.parseInt(st.nextToken());  
        int V = Integer.parseInt(st.nextToken());  
  
        int Quotient = (V-B) / (A-B);  
        int Remainder = (V-B) % (A-B);  
        if (Remainder != 0) Quotient++;  
        sb.append(Quotient);  
  
  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
  
  
}
```

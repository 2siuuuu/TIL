백준 - 2231 - 분해합

https://www.acmicpc.net/problem/2231

입력값으로 어떤 수 의 분해합이 주어진다.

나는 그 분해합에 해당하는 생성자를 구해야 하는데,
생성자가 무엇이냐에 따라 입력값으로 주어지는 수를 만드는 생성자는 여러 개가 나올 수 있다.
그 여러 개의 생성자 중 최댓값과 최솟값이 있을 것인데, 나는 최솟값이 되는 생성자를 답으로 내면 되는 것이다.

예를 들어 입력값으로 216이 주어졌을 때, 내 계산으로는 2개의 생성자가 나온다.

1. 198
2. 207
1번을 다 더하면 216.
2번을 다 더해도 216. 
나는 최솟값을 답으로 내야 하므로 198을 말하면 되는 것이다.

이것을 어떻게 구해야 할까?
간단하게 구하려면 생성자를 1로 놓고 1씩 늘려가며 찾으면 된다. 그러다가 분해합이 입력값이 되는 첫 번째 순간이, 정답을 찾는 순간이 될 것이다.

그런데 문제에서는 생성자가 없는 경우도 존재할 수 있다고 한다.
이 문제에서 생성자는 분해합보다 무조건 작아야 성립한다.

분해합이 2이면 생성자는 1이고 1+1이므로 2다. 
그러나 분해합이 1이면 ? 생성자는 무조건 1보다 작아야 하는데 0.5+0.5가 아닌 이상 생성자는 없다. 즉 이 경우엔 없다고 봐야 하므로 답은 0으로 출력하면 된다.

그럼 분해합이 1인 경우 말고도 생성자가 없는 경우가 존재하는가? 있다.

이 전에 경우 분해합이 2, 즉 입력값이 2라면 2 = 1+ (1) 이므로 생성자는 1이며 따라서 생성자는 존재한다.

그러나 입력값이 3이라면 ? 생성자를 1로 놓고 1씩 늘려보자.
3 != 1 + 1
3 != 2 + 2 
생성자가 2인 시점에서 분해합이 3이 되지 않았다면 더 이상 생성자를 늘릴 순 없다. 왜냐하면 생성자는 분해합보다 무조건 작아야 하니까. 
즉 생성자가 없는 경우는 생각보다 많이 존재할 것이다.

그럼 나는 생성자가 없는 경우를 어떻게 필터링 하면 될까?
생성자를 저장하는 변수에 1을 초기화 한다. 왜냐하면 생성자가 0일 수는 없으니까. 0이면 그 자체로 생성자가 없다는 뜻이니까.

그 이후 if문으로 들어간다. 조건식 : 생성자가 입력값보다 작은가?
만약 크거나 같다면 입력값은 생성자가 존재하지 않는 것이다.
생성자가 입력값보다 작다면, 이제 생성자와 생성자를 분해한 수와의 덧셈을 해서 입력값이 되는지 확인하면 된다.
생성자가 1부터 시작하고, 입력값보다 작은 시점에서, 그들의 분해합이 입력값을 넘어갈 수는 없다.

계산 결과가 입력값보다 작으면, 생성자에 1을 더해서 다음 반복으로 넘어가면 되고,
입력값에 도달했다면, 그 시점이 정답인 시점인 것이다.


그럼 나는 정답을 찾기까지 몇 번을 반복해야 할까?
최악의 경우는 몇일까?
N이 1,000,000 이라면?
생성자는 무조건 1,000,000 보다 미만인 수이다.
생성자가 1부터 시작하여 1씩 증가한다고 했을 때 반복문이 도는 횟수는 1,000,000을 넘어서는 안 된다. 


분해는 어떻게 해야 할까?
1의 자리 수는 그냥 같은 수를 더하면 되지만 
10의 자리 수 부터는 분해를 해야 한다.
지금 떠오르는 방법은 문자열로 변환해서 슬라이싱 하는 것이다.
이 방법대로 한다면,
생성자를 문자열로 바꾼 뒤,
문자열의 크기만큼 반복하여 문자열을 잘라내며 값을 더하면 될 것이다.

# 1차 시도 - 성공

```java
import java.io.*;  
import java.util.StringTokenizer;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //N  
        int N = Integer.parseInt(br.readLine());  
  
        int answer = 0;  
        //생성자 초기화  
        for (int mom = 1; mom < 1000000; mom++) {  
            //전제 조건 : 생성자는 입력값보다 작아야 한다.  
            if (mom >= N) break;  
            //생성자를 분해해서 다 더한다.  
            String sMom = String.valueOf(mom);  
            int target = mom;  
            //분해한거 더한 값 = 생성자 + 분해 + 분해 + 분해  
            for (int i = 0; i < sMom.length(); i++) {  
                target += sMom.charAt(i) - '0';  
            }  
  
            //다 더한 값과 N을 비교한다. 작은가? 같은가?  
            if (target == N) {  
                answer = mom;  
                break;  
            }  
            //정답이 아니면 다시 반복  
        }  
        //결과 : 0이거나 정답이거나  
        sb.append(answer);  
  
        //출력  
        bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

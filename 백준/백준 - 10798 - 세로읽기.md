백준 - 10798 - 세로읽기

https://www.acmicpc.net/problem/10798


`char[5][15]` 의 크기 배열 선언

여기에 일단 입력되는 단어를 다 채운다.
그리고 각 단어를 입력할 때 어떤 단어가 가장 길이가 긴지 기록해둬야 한다. 그 이유는 아래에서 설명됨.

출력을 해야 하는데,
만약 단어가 다음과 같이 주어진다면
1
111111111111111
1
1
1
세로로 출력해야 하니까 15번 출력해야 한다.

출력할 때 반복 기준은 5개 중 가장 긴 단어 길이.
위의 예에선 15이다.

그래서 단어를 채울 때 최대 길이를 기록해 둔다.

그리고 출력할 때는 `board[j][i]` `i`, `j` 순서 주의.

char 타입의 배열에 초기화되는 값은 nul이고 문자로는 `'\u0000'` 임

```java
import java.io.BufferedReader;  
import java.io.BufferedWriter;  
import java.io.IOException;  
import java.io.InputStreamReader;  
import java.io.OutputStreamWriter;  
import java.util.Arrays;  
import java.util.StringTokenizer;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        char[][] board = new char[5][15];  
  
        // 채우기  
        int maxLength = 0;  
        for(int i = 0; i < 5; i++) {  
            String st = br.readLine();  
            maxLength = Math.max(maxLength, st.length());  
  
            for (int j = 0; j < st.length(); j++) {  
                board[i][j] = st.charAt(j);  
            }  
        }  
  
        //출력  
        for(int i = 0; i < maxLength; i++) {  
            for (int j = 0; j < 5; j++) {  
                if(board[j][i] != '\u0000') {  
                    sb.append(board[j][i]);  
                }  
            }  
        }  
  
  
  
  
  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
  
  
}
```

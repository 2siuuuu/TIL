https://www.acmicpc.net/problem/10810

바구니는 여러 개 있다.  각 바구니에는 1번 ~ N번이라는 번호가 매겨진다

공도 마찬가지다.

바구니에 넣을 수 있는 공은 단 한 개
맨 처음 바구니는 빈 바구니이다.

1 2 3 
1번 바구니 ~ 2번 바구니 까지 3번 공을 넣는다.
1번 바구니에 3번 공이 들어가고
2번 바구니에 3번 공이 들어간다.

그 다음 입력 3 4 4 이면
3번 ~ 4번 바구니에 4번 공을 넣는다
4번 공을 다 넣은 시점에서 

1번 바구니에 3번공
2번 바구니에 3번공
3번 바구니에 4번공
4번 바구니에 4번공.

이런 식으로 맨 마지막 차례로 공을 넣기가 끝나면 그 결과를 출력하는 것이다.
1~ 5번 바구니에 몇 번 공이 들어 있는지.

N은 예를 들어, N이 3이라면

3개의 바구니가 생성된다고 생각하자.

그리고 M이 3이라면 
총 3번 공을 넣는 것인데, 다음과 같다.

1번 바구니 ~ 2번 바구니에 2번 공을 넣는다
-> 공을 다 넣었으면 총 3번 중 1번 충족.

2번 바구니 ~ 3번 바구니에 1번 공을 넣는다
-> 공을 다 넣었으면 총 3번 중 2번 충족.

이런 식이다.

***

로직 구현

N을 입력받는다.
N은 다음과 같은 의미를 가진다
- 바구니가 가질 수 있는 번호는 1부터 N 까지
- 공이 가질 수 있는 번호도 1부터 N 까지
- j번 바구니는 N을 초과할 수 없다
- 공의 번호 k는 N을 초과할 수 없다

M을 입력 받는다.
M은 다음과 같은 의미를 가진다
- 공을 M회 넣는다
- 반복 수 를 의미한다.


1번 시도 : 런타임 에러 ArrayIndexOutOfBounds

```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        StringTokenizer NandM = new StringTokenizer(br.readLine());  
        int N = Integer.parseInt(NandM.nextToken());  
        int M = Integer.parseInt(NandM.nextToken());  
  
        int[] lists = new int[N];  
  
        for (int i = 0; i < M; i++) {  
            StringTokenizer ijk = new StringTokenizer(br.readLine());  
            int I = Integer.parseInt(ijk.nextToken());  
            int J = Integer.parseInt(ijk.nextToken());  
            int K = Integer.parseInt(ijk.nextToken());  
  
            // 공 넣기  
            for (int j = I; j <= J; j++) {  
                lists[j] = K;  
            }  
        }  
  
        // 출력  
        for (int list : lists) {  
            sb.append(list).append(' ');  
        }  
  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
}
```

원인:
공 넣기 코드에 오류가 있었다.
바구니가 총 3개 있는데 2번 바구니부터 3번 바구니에 공을 넣는다고 하자.
그럼 배열의 2번째 인덱스와 3번째 인덱스에 공을 넣으면 된다.
그런데 배열의 인덱스는 0부터 시작한다. 
2번 바구니와 3번 바구니에 넣는다고 배열의 2번인덱스 3번 인덱스에 넣으면 3번 인덱스에 넣을 때 배열의 크기를 초과하기 때문에 런타임 에러가 발생할 수 밖에 없다.
이 점을 간과하여 코딩했다.

공넣기 코드에 j-1을 넣어 오류를 수정했다.

수정 결과: 성공!

```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        StringTokenizer NandM = new StringTokenizer(br.readLine());  
        int N = Integer.parseInt(NandM.nextToken());  
        int M = Integer.parseInt(NandM.nextToken());  
  
        int[] lists = new int[N];  
  
        for (int i = 0; i < M; i++) {  
            StringTokenizer ijk = new StringTokenizer(br.readLine());  
            int I = Integer.parseInt(ijk.nextToken());  
            int J = Integer.parseInt(ijk.nextToken());  
            int K = Integer.parseInt(ijk.nextToken());  
  
            // 공 넣기  
            for (int j = I; j <= J; j++) {  
                lists[j-1] = K;  
            }  
        }  
  
        // 출력  
        for (int list : lists) {  
            sb.append(list).append(' ');  
        }  
  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
}
```

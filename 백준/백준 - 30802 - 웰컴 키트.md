백준 - 30802 - 웰컴 키트

https://www.acmicpc.net/problem/30802


시간 제한이 0.1초
1초가 1000ms
0.1초는 100ms
하지만 채점 현황 게시판을 확인한 결과 심지어 0.3초를 넘겨도 통과된 이력이 많이 보여서, 0.1초 내로 통과해야 한다는 것을 신경 쓰지 않기로 했다.


***
- 아레나 A - 웰컴 키트를 준비하는 주체 (행사 주최)
- 참가자 B - 준비된 월컴 키트를 소비하는 주체 (키트 최종 소비자)
- 키트 제작 업체 C - 웰컴 키트를 만드는 주체. (상품을 만듦)
- 키트 재료 제작 업체 D - C에게 재료를 주문받아 납품하는 주체 (상품의 재료를 제작)

키트의 구성 - 티셔츠 1장, 펜 1자루

**상황 이해**
이 문제에서 상황의 주인공은 C이다.
C가 D에게 물량을 주문하는 상황임. 이 때 C는 D에게 주문서를 작성해야 하는데 이 문제의 출력 값이 그 주문서에 포함될 것이다


**입력값 이해**
첫줄 N은 참가자 수

그런데 셋째 줄의 의미가 뭐임?
T = 티셔츠 묶음 수
P = 펜의 묶음 수

C는 참가자가 얼마나 올 것이며 각 참가자들이 주문한 티셔츠의 사이즈 별 갯수도 알고 있다. 그걸 입력으로 준 것은 타당함

아하 제작 업체 D는 낱개로는 주문 받지 않는 것이다. (펜은 예외)


업체는 티셔츠를 한 묶음에 5개씩 팔고,
펜을 한 묶음에 7개 판다

티셔츠의 경우를 생각해본다
티셔츠는 남아도 된다.
만약에 사이즈 별로
3 1 4 1 5 9
이면
S사이즈 3명에 1 묶음을 할당하고 2벌 남음
M사이즈 1명에 1묶음을 할당 4벌 남음
L사이즈 4명에 1묶음을 할당 1벌 남음
XL사이즈 1명에 1묶음을 할당 4벌 남음
XXL사이즈 5명에 1묶음 안 남음
XXL사이즈 9명에 2묶음 1벌 남음
티셔츠는 총 7묶음이 필요한 것을 확인했다.

7 묶음을 어떻게 구할 수 있음?
3 - 5 = -2
: 1

1 - 5 = -4
: 1

4 - 5 = -1
: 1

1 - 5 = -4
: 1

5 -5 = 0
: 1

9 -5 = 4 <- 1증가
4 - 5 = -1 <- 1증가
: 2

즉 음수이거나 결과가 0이 될 때까지 T를 신청자 수로 빼고 뺀 횟수만큼 1 증가시킨 수를 합산하여 총 묶음 수를 구할 수 있다.


펜은 어떻게 구하는가
주어진 P 는 1 묶음에 들어가는 펜의 자루 수
한 명에 하나씩이니까
P X ?묶음 <= N 이어야 한다.
이때 ?묶음을 구하기 위해 N/P 의 몫과 나머지를 구해야 한다.

이 때 몫이 두 번째 출력의 첫 번째 답, 나머지가 두 번째 답이다.


# 1차 시도 - 정답

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        StringBuilder sb = new StringBuilder();


        // N입력
        int N = Integer.parseInt(br.readLine());

        // 사이즈 별 인원
        StringTokenizer st = new StringTokenizer(br.readLine());

        // T,P
        StringTokenizer TP = new StringTokenizer(br.readLine());
        int T = Integer.parseInt(TP.nextToken());
        int P = Integer.parseInt(TP.nextToken());

        int answer1 = 0; // 티셔츠 몇 묶음
        int answer2 = 0; // 펜 몇 묶음
        int answer3 = 0; // 추가 펜

        // answer1 구하기
        for (int i = 0; i < 6; i++) {
            int token =  Integer.parseInt(st.nextToken());
            while (token != 0 && !(token < 0)) {
                token -= T;
                answer1++;
            }
        }

        //answer2,3 구하기
        answer2 = N/P;
        answer3 = N%P;

        //출력
        sb.append(answer1).append('\n').append(answer2).append(' ').append(answer3);

        //출력
        bw.write(sb.toString());
        bw.flush();
        bw.close();
        br.close();
    }

}
```

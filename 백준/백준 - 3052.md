https://www.acmicpc.net/problem/3052


입력은 총 10개이며 각 줄에 1개씩이다.

테스트 케이스 1번의 첫번 째 줄에 입력되는 숫자가 3이라면

3에 대한 42의 나머지는 3이다. 

둘째 줄의 입력이 2라면

2에 대한 42의 나머지는 2이다.
이런 식으로 10번을 입력받는다. 만약

10개의 나머지가 모두 같으면 출력은 1.

절반씩 같으면 2.
모두 다르면 10 으로 출력하면 된다.

***
로직: 서로 다른 나머지가 몇 개 있는지 세는 방법을 구현하기

나머지는 최대 10개가 나오므로 int형 배열을 선언하고 크기는 10으로 한다.

만약 입력이 총 3개이고 어떤 수들에 대한 나머지가 각각 1,2,3인 경우
입력이 총 3개이므로 배열의 크기도 3개로 한다.
먼저 첫번 째로 입력된 수에 대한 나머지를 배열의 첫번 째 공간에 입력할 것이다.
그러나 입력 전, 배열을 순회하여 입력한 나머지와 같은 수가 있는지 검사하고 없다면 입력한다.
즉 로직이 아래와 같다.
- 나머지가 1인 경우:
1. 먼저 배열을 순회하여 배열에 1이 있는지 검사한다.
2. 없다면 나머지에 해당하는 값 1을 배열의 첫번 째 인덱스에 삽입한다.
3. 있다면 pass. 다음 나머지를 입력할 준비를 한다.
이 로직이라면 나머지가 모두 다른 경우도, 같은 경우도 대비 가능하다.

정리:

1. 10번의 입력 중 첫번 째 입력을 받아 저장한다
2. 입력값과 42에 대하여 나머지 연산을 수행하고 결과값을 저장한다.
3. 결과값을 배열에 넣을 준비를 한다.
	- 만약 배열 안에 같은 수가 있다면 배열에 결과값을 넣지 않는다.
	- 없다면 배열의 첫번 째 인덱스에 결과값을 저장한다. (이후 차례차례 결과값을 배열에 입력한다.)
4. 입력이 모두 완료되면 배열의 요소의 갯수를 세어 출력한다.


***
구현

같은 값이 있는지 조사하고 없다면 저장, 아니면 패스. 이 로직을 어떻게 구현해야 하는가?
현재 나머지를 구했고 그 값들이 1,3,1이라고 하자.
1. 배열에 1을 넣을 준비
2. 10번을 반복하는 for문 시작
3. 조건1 - 배열의 현재 인덱스에 해당하는 요소가 1이 아닐 경우에만 1을 저장해야 한다. 즉 서로 같으면 이미 저장되어 있다는 의미이므로 저장하지 않는다.
4. 조건2 - 현재 인덱스가 0일 경우에만 1을 저장해야 한다.
5. 조건 1과 조건 2는 && 연산으로 묶어서 if문의 조건식으로 작성해야 한다.
	- 그 이유는 만약 현재 배열의 인덱스의 요소가 저장하려는 값과 같지 않더라도 그 값이 이미 저장되어 있는 다른 값이면 무조건 덮어쓰기 하기 때문이다.
6. 저장 직후 break한다. for문을 빠져나와야 다음 입력을 받으며 검사를 처음부터 진행할 수 있으므로.
7. 이후 3을 넣을 준비를 한다.
8. 첫 번째 인덱스에는 1이 저장되어 있다. 조건1과 조건2에 의해 1 != 3 이고 1 != 0 이므로 첫번 째 인덱스를 pass하여 두번 째 반복이 시작된다.
9. 두번 째 인덱스의 요소는 0으로 초기화되어 있으므로 3이 아니고, 0이므로 3은 두번 째 인덱스의 요소로서 저장된다. 직후 for문을 빠져나온다.

이런 프로세스를 반복하면 배열에 중복되는 값이 처리되어 모든 나머지 값이 첫번 째 요소부터 차례로 채워진다.


출력 시 배열의 첫번 째 요소부터 마지막 요소까지 순회하여 나머지값이 어디까지 저장되어 있는지 확인하고 그 인덱스의 숫자를 출력하면 된다.

하지만 배열의 전체 공간을 순회할 필요 없다. 다음 로직에 따라서 처리하면 배열의 끝까지 순회할 필요는 없게 된다.

1. 10번의 반복을 수행하는 for문 시작
2. if 조건 1 - 배열의 현재 인덱스 값에 해당하는 요소가 0일 경우 아래 문장을 수행한다.
- 이전 인덱스 값을 저장한다.
- break
3. 저장한 값을 출력한다.

주의해야 할 점은, 만약 배열에 저장된 값이 1,2,3,0일 경우, 0이 저장되어 있는 공간의 인덱스 번호는 3이다. 이경우 이전 인덱스의 값은 2라고 할 수 있겠지만 출력해야 하는 건 배열에 저장된 나머지 값의 갯수이다. 배열에는 총 3개의 나머지 값이 저장되어 있으므로 2+1 == 3이다. 즉 나는 현재 인덱스 값의 요소가 0인 경우 인덱스 값 i를 그냥 저장해서 출력하면 되는 것이다. 


첫 번째 시도:
```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //배열 선언  
        int[] lists = new int[10];  
  
        //나머지 연산과 나머지 값 저장.  
        for (int i = 0; i < 10; i++) {  
            int num = Integer.parseInt(br.readLine());  
            int mod = num % 42;  
            //배열에 mod 저장  
            for (int j = 0; j < 10; j++) {  
                //같은 값이 있는지 조사.  
                if (!(lists[j] == mod) && lists[j] == 0) {  
                    //배열의 현재 인덱스에 mod와 같은 값이 없으면 저장한다.  
                    //근데 현재 인덱스가 만약 같은 값 외의 값이면 무조건 덮어쓰기 한다. 그러므로 조건은 현재 인덱스가 0일 경우에만 저장해야 하고, 직후 break해야 한다.  
                    lists[j] = mod;  
                    break;  
                }  
            }  
        }  
  
        //개수 세기  
        int result = 0;  
        for (int i = 0; i < 10; i++) {  
            if (lists[i] == 0) {  
                result = i;  
                break;  
            }  
        }  
  
        //출력  
        bw.write(String.valueOf(result));  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
}
```

원인:

- **방법 1**
배열에 mod 값을 저장하는 분기문 조건에 논리적인 오류가 있었다.
내가 원하는 시나리오는 다음과 같다.
1,2,1을 저장한다고 하자
1. 1을 첫번 째 인덱스에 저장한다
2. 2를 두번 째 인덱스에 저장한다.
3. 1이 이미 첫번 째 인덱스에 있으므로 저장하지 않고 패스한다.
4. 저장이 끝난다

현재 내가 작성한 로직은 다음의 오류가 있다.
- 현재 배열의 값이 mod와 같지 않아야 한다
- 현재 배열의 값이 0이어야 한다.
그런데 1이 두 번 연속으로 들어온다고 가정하고, 이미 배열의 첫번 째 인덱스에 1이 저장되었다고 가정하자.
현재 배열의 두번 째 공간에 대해 if문 조건식 검사를 진행 중이다.
현재 배열의 두번 째 공간에는 0이 저장되어 있다.
- 현재 배열의 값이 mod와 같지 않아야 한다 -> mod : 1 이므로 같지 않다
- 현재 배열의 값이 0이어야 한다. -> 현재 배열의 값은 0이다.
즉 위 조건 두 개를 동시에 만족하므로 두번 째 공간에 1이 저장된다. 그러나 저장되지 않아야 한다.
조건식이 잘못되었다.

**방법2**
방법 1을 폐기하고 새로운 방법으로 시도해본다.

target을 잡고 target이 배열에 몇 개 있는지 센다.
- 순회를 돌 때 해당 값이 어느 인덱스에 있는지 확인할 수 있다. 
- 그 인덱스 값을 저장하는 배열을 따로 선언하여 거기에 차례로 저장한다.



두번 째 시도 : 
```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //배열 선언  
        int[] lists = new int[10];  
  
  
        //나머지 연산과 나머지 값 저장.  
        for (int i = 0; i < 10; i++) {  
            int num = Integer.parseInt(br.readLine());  
            int mod = num % 42;  
            //배열에 mod 저장  
            lists[i] = mod;  
        }  
  
        //개수 세기  
        int[] arr = new int[10];  
        int top = 0;  
  
        int result = 0;  
        for (int value : lists) {  
            if (contains(arr, value)) {  
                continue;  
            }  
            for(int i = 0; i < value; i++) {  
                if (value == lists[i]){  
                    arr[top++] = i;  
                }  
                // 반복을 모두 마치면  value와 같은 값이 있는 lists의 인덱스 번호가 arr에 차례로 저장된다.  
                //반복을 마친 후, result는 1 증가해야 한다. 서로 다른 나머지의 갯수를 세므로 몇 개든 종류만 다르면 갯수를 하나 세야 하기 때문이다.  
            }  
            result++;  
        }  
          
        //출력  
        bw.write(String.valueOf(result));  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
    private static boolean contains(int[] arr, int value) {  
        for (int x : arr) {  
            if (x == value) return true;  
        }  
        return false;  
    }  
  
}
```

결과 : ArrayIndexOutOfBounds


원인: 사실 분석할 수 있긴 한데 귀찮기도 하고 애초에 문제 접근이 좀 꼬인 것 같아서 다시 처음부터 생각해보았다.

contains 메서드를 하나 선언한다. contains 메서드는 인자로 lists와 mod를 넘기고, 하는 일은, lists안에 찾는 값이 있는지 없는지 여부를 boolean으로 반환한다.

인자로 넘기는 lists가 0으로 초기화 되어 있다면 초기화된 공간과 0으로 계산된 mod값과 구분하기 어렵다. 그래서 배열의 모든 공간을 -1로 초기화 한다. 

세번 째 시도:
```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //배열 선언  
        int[] lists = new int[10];  
        Arrays.fill(lists, -1); // -1로 초기화 한 이유 : 나머지 연산 결과가 0인 것들도 있다. 이 때 배열의 공간이 0으로 초기화 되어 있다면 구분이 어렵다.  
        // -1로 초기화 하면 contains메서드의 오동작을 우려할 필요가 없어진다.  
  
  
        //나머지 연산과 나머지 값 저장.  
        int top = 0;  
        for (int i = 0; i < 10; i++) {  
            int num = Integer.parseInt(br.readLine());  
            int mod = num % 42;  
            //배열에 mod 저장 - 차례대로 저장해야 함.  
            if (!contains(lists, mod))  {  
                lists[top++] = mod;  
            }  
        }  
  
        //출력  
        bw.write(String.valueOf(top));  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
    private static boolean contains(int[] arr, int value) {  
        for (int x : arr) {  
            if (x == value) return true;  
        }  
        return false;  
    }  
  
}
```

10813 - 공 바꾸기
https://www.acmicpc.net/problem/10813

바구니는 N개

바구니가 3개 있다면 N은 3이다

3개의 바구니가 있다면 

첫 번째 바구니에는 1번 공이 들어있고
두 번째 바구니에는 2번 공이 들어있고
세 번째 바구니에는 3번 공이 들어있다.

그리고 공을 교환한다.
만약 첫째 바구니와 셋째 바구니를 교환한다면
첫째 바구니에는 3번 공이,
셋째 바구니에는 1번 공이 들어가게 된다.
이때 i == 3, j == 1 이다.

한 번만 교환한다면, 즉 M이 1이라면 
최종 결과는
3 2 1이 된다.

***
로직 짜기

먼저 N과 M을 입력받는다.

먼저 바구니에 공을 담아야 한다.
바구니의 번호와 동일한 공을 담아야 하므로
바구니의 갯수만큼 순회하여 바구니에 공을 담으면 된다.

공을 담았다면 이제 어떻게 공을 교환할 것인지 주어지는 입력을 받는다.
입력으 받는 횟수는 M이다. M번 반복하여 입력을 받으면 된다.

1회 반복에 공을 교환하여 바구니에 저장하는 행위를 수행하면 된다.
공을 교환하는 방법은 다음과 같다.
1. 임시 변수 temp를 선언
2. I번째 바구니 안에 있는 공을 temp에 저장
3. J번째 바구니 안에 있는 공을 I번째 바구니에 저장
4. temp에 있던 공을 J번째 바구니에 저장.
5. 교환 끝.

교환이 끝나면 바구니의 현황을 출력하면 된다.

문자열을 한 번에 출력하기 위해 stringbuilder로 문자열을 만든다.
for문을 사용해 바구니 안을 순회하며 요소를 뽑아 sb에 추가한다.

질문: sb에 추가한다는 건 자세히 뜯어보면 어떻게 데이터가 추가되고 있는 것인지 알아보자


첫 번째 시도: 오답 - NumberFormat

```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
  
        //입력  
        StringTokenizer NandM = new StringTokenizer(br.readLine());  
        int N = Integer.parseInt(NandM.nextToken());  
        int M = Integer.parseInt(NandM.nextToken());  
  
        //바구니  
        int[] basket = new int[N];  
        //바구니 채워  
        for (int i = 0; i < N; i++) {  
            basket[i] = i+1;  
        }  
  
        //교환  
        for(int i = 0; i < M; i++) {  
            int I = Integer.parseInt(br.readLine());  
            int J = Integer.parseInt(br.readLine());  
            int temp;  
            temp = basket[I-1];  
            basket[I-1] = basket[J-1];  
            basket[J-1] = temp;  
        }  
  
        //문자열 만들기  
        for(int ball : basket) {  
            sb.append(ball).append(' ');  
        }  
  
        // 출력  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
}
```

오답이었던 이유:

i, j의 입력은 한 줄로 이루어진다.
한 줄에 i와 j가 모두 주어진다.
그런데 나는 교환 부분에서 i와 j를 각각 다른 줄로 입력 받는다.
그러니 오류가 발생할 수 밖에 없다.

백준 - 5622 - 다이얼

https://www.acmicpc.net/problem/5622
WA 이면
W는 숫자 9 -> +1초 -> 10초 
: W입력에 걸리는 시간 : 10초

A는 숫자 2 -> +1초 -> 3초
A입력에 걸리는 시간 : 3초

= 13초


다이얼의 숫자는 알파벳으로 이루어진 문자열을 가지고 있다
예를 들어 다이얼의 숫자 중 2가 가진 문자열은 ABC이다.
입력으로 주어지는 알파벳이 B라면, 다이얼 상의 숫자 2를 걸면 된다.
C, A여도 마찬가지이다. 

***
문제 풀이

문자열 입력 받기

문자열 분해

알파벳 하나가 다이얼 상 어느 숫자에 해당하는지 판단하기

ABC
DEF
GHI
JKL
MNO
PQRS
TUV
WXYZ

위 데이터를 각각의 문자열로 만들어서 String 배열에 넣기

단어 검색 :

입력된 알파벳이 A라면

"ABC" 문자열 안에 A가 포함되는지 확인하고, 포함된다면 "ABC"에 해당하는 숫자 2, 그리고 그 숫자를 다이얼로 거는 데 걸리는 시간 3초를 더하면 된다.

```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        // 알파벳 입력  
        String word = br.readLine();  
  
        String[] dial= {"ABC","DEF","GHI","JKL","MNO","PQRS","TUV","WXYZ"};  
  
        //  
        int total = 0;  
        for (int i = 0; i < word.length(); i++) {  
            char alphabet = word.charAt(i);  
            // 검색  
            for (int j = 0; j < dial.length; j++) {  
                if (dial[j].contains(String.valueOf(alphabet))) {  
                    //찾았음  
                    total += j+3;  
                }  
            }  
        }  
  
        //출력  
        bw.write(String.valueOf(total));  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

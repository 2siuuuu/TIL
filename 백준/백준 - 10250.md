백준 - 10250

https://www.acmicpc.net/problem/10250

H는 층

W는 엘리베이터와 가까운 거리부터 끝까지의 방 개수

N 번째 손님

배정 순서:
방 번호가 1001일 때, X는 10이고 Y는 1이다.

5번째 손님일 경우, 그 손님이 배정되는 방 번호는
501이다.

손님에게 배정되는 방의 번호는 1부터 N까지 순차적으로 증가하고, 규칙이 존재한다.

그리고 그 규칙에 따라서 N 번째 손님이 배정받는 방 번호의 경우의 수를 일렬로 나열했을 때, 방 번호는 101호, 102호, ... YYXX호 이다.
이 배열을 A라고 하자.

그리고 N번 손님이 호텔 로비에 도착한 직후 손님이 머물 방 번호를 고르는 직원의 이름은 count이고, count는 머릿속에서 A의 처음부터 마지막까지 순차적으로 가리킨다.

count는 머릿속에서 A의 첫 번째 부터 세기 시작하고, N번에 다다랐을 때, 세기를 멈춘 그 시점의 방 번호를 N번 손님에게 배정한다.
즉 그 시점에서 count가 A의 첫 번째부터 센 횟수는 정확히 N과 동일하다.

즉 나는 이 문제를 count를 사용하여 해결하였다.

```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //T 입력 받기.  
        int T = Integer.parseInt(br.readLine());  
  
        for (int i = 0; i < T; i++) {  
            // HWN입력받기  
            StringTokenizer st = new StringTokenizer(br.readLine());  
            int H = Integer.parseInt(st.nextToken());  
            int W = Integer.parseInt(st.nextToken());  
            int N = Integer.parseInt(st.nextToken());  
  
            int Y = 0;  
            int X = 0;  
            int count = 0;  
            for (int w = 0; w < W; w++) {  
                for (int h = 0; h < H; h++) {  
                    count++;// N번째 손님의 방을 정하는 타이밍을 결정하는 카운터  
                    if(count == N){  
                        Y = h+1;  
                        X = w+1;  
                        break;  
                    }  
                }  
            }  
  
            //방 번호 생성  
            sb.append(Y);  
            if (X < 10) {  
                sb.append(0).append(X);  
            }  
            else {  
                sb.append(X);  
            }  
  
            sb.append('\n');  
        }  
  
        //출력  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

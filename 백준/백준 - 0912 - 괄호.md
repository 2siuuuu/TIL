# 1차 시도
```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        StringBuilder sb = new StringBuilder();

        //T 입력
        int T = Integer.parseInt(br.readLine());
        for  (int tt = 0; tt < T; tt++) {
            // PS 입력
            String ps = br.readLine();
            int leftPs = 0;
            int rightPs = 0;
            for (int i = 0; i < ps.length(); i++) {
                if (ps.charAt(i) == '(') leftPs++;
                else rightPs++;
            }
            String answer = leftPs == rightPs ? "YES" : "NO";
            sb.append(answer).append('\n');
        }

        //출력
        bw.write(sb.toString());
        bw.flush();
        bw.close();
        br.close();
    }

}
```

## 풀이 과정
`(` , `)` 의 각 갯수가 서로 다르다면 무조건 VPS가 아니다

`(`의 갯수를 세는 변수, `)`의 갯수를 세는 변수를 각각 만들어서
각각의 갯수를 세고 두 갯수가 같은지 다른지 검사하는 방법을 사용했다.


# 2차 시도

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        StringBuilder sb = new StringBuilder();

        //T 입력
        int T = Integer.parseInt(br.readLine());
        for  (int tt = 0; tt < T; tt++) {
            // PS 입력
            String ps = br.readLine();
            int stack = 0;
            for (int i = 0; i < ps.length(); i++) {
                if (ps.charAt(i) == '(') stack++;
                else stack--;
                if (stack < 0) {
                    break;
                }
            }
            String answer = stack == 0 ? "YES" : "NO";
            sb.append(answer).append('\n');
        }

        //출력
        bw.write(sb.toString());
        bw.flush();
        bw.close();
        br.close();
    }

}
```

## 풀이 과정:

반례가 있었다. `)(` -> 각 기호의 갯수는 동일하지만 VPS가 되는 조건은 만족하지 못한다.

그러므로 풀이 방법을 stack의 push, pop 원리를 활용하여 해결했다.
push : +1
pop : -1

VPS가 되려면 무조건 push가 먼저 와야 한다.
pop이 먼저 오거나, PS 문자열의 검사 결과 0이 아니라면 VPS가 아니다.

pop이 먼저 될 경우를 고려하면 문제를 해결할 수 있다.

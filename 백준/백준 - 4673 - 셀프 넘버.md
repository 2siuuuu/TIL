# 나의 방법

정수를 문자열로 바꾸고 하나씩 추출해서 다시 더함

```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        StringBuilder sb = new StringBuilder();

        for (int target = 1; target <= 10000; target++) {


            boolean isSelf = false;
            int result = 0;
            for (int i = 1; i <= target; i++) {
                result = i;
                //분해
                String str = Integer.toString(i);
                for (int j = 0; j < str.length(); j++) {
                    result += Integer.parseInt(String.valueOf(str.charAt(j)));
                }

                if (result == target) {
                    isSelf = true;
                    break;
                }
            }

            if (!isSelf) {
                sb.append(target).append("\n");
            }

        }


        bw.write(sb.toString());

        bw.flush();
        bw.close();
        br.close();
    }



}
```


# GPT

n에서 각 자릿수를 추출하는 방법을 정수 연산으로 구현.
***
지금 코드는 “각 target마다 1~target까지 전부 검사”해서, 대략 O(N²)이라 10000에서 시간이 튀는 게 정상이에요. (문자열 변환까지 있어서 더 느림)

방법은 바꿔야 합니다. target을 찾지 말고, “생성되는 수를 미리 표시”하세요.

핵심 아이디어

1. 1~10000의 모든 n에 대해 d(n)을 계산해서
    
2. 그 결과를 boolean 배열에 체크
    
3. 체크 안 된 수만 출력 (그게 셀프 넘버)
    

그리고 자리수 합은 String 변환 대신 정수 연산으로 하면 더 빨라요.

아래처럼 바꾸면 보통 아주 넉넉하게 1초 안에 들어옵니다.

```java
import java.io.*;
import java.util.*;

public class Main {
    static int d(int n) {
        int res = n;
        while (n > 0) {
            res += (n % 10);
            n /= 10;
        }
        return res;
    }

    public static void main(String[] args) throws Exception {
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        StringBuilder sb = new StringBuilder();

        final int MAX = 10000;
        boolean[] generated = new boolean[MAX + 1];

        for (int n = 1; n <= MAX; n++) {
            int g = d(n);
            if (g <= MAX) generated[g] = true;
        }

        for (int i = 1; i <= MAX; i++) {
            if (!generated[i]) sb.append(i).append('\n');
        }

        bw.write(sb.toString());
        bw.flush();
    }
}
```

추가로 네 코드에서 느린 포인트는 이것들이에요.

- `target`마다 `i=1..target` 반복 (가장 큰 문제)
    
- `Integer.toString(i)`, `String.valueOf(char)`, `Integer.parseInt(...)` 같은 문자열/파싱 비용
    

위 방식으로 바꾸면 구조적으로 시간이 줄어듭니다.

## 자릿수 추출의 아이디어

예를 들어 123을 123+1+2+3으로 계산하는 방법은
n == 123일 때
n을 먼저 result변수에 저장

반복 시작

n % 10 -> 나머지는 3
3을 result에 더함

n / 10 -> 몫은 12
12를 n에 대입

1회차 반복 끝

이런 식으로 n이 0이 될 때 까지 반복. 
이런 식으로 계산하면 123+3+2+1 순서로 더해짐.

백준 - 1018 - 체스판 다시 칠하기
https://www.acmicpc.net/problem/1018

# 풀이 과정 1
결과적으로 보드에는 체스판 처럼 검/흰 색이 나타나면 된다.

그러기 위해서 칠해야 되는 횟수를 구하면 된다.

보드의 크기는 8X9 라면
세로가 8
가로가 9이다.

10 13일 경우
아래와 같은 예시 입력이 주어진다
BBBBBBBBWBWBW 4
BBBBBBBBBWBWB 4
BBBBBBBBWBWBW 4
BBBBBBBBBWBWB 4
BBBBBBBBWBWBW 4
BBBBBBBBBWBWB 4 v
BBBBBBBBWBWBW 4 v
BBBBBBBBBWBWB 4 v
WWWWWWWWWWBWB 5
WWWWWWWWWWBWB 5

칠해야 하는 최솟값이 있다면 최댓값도 있다는 뜻이다.
내 계산으로는 42번 칠해야 한다.
하지만 이 예시 답안의 답은 12이다.
최댓값 : 42
최솟값 : 12
12번만 칠해도 10x13 크기의 보드가 체스판처럼 칠이 된다는 뜻인가?

그런데 문제에서는 보드를 8x8크기로 잘라낸다고 한다. 그런데 입력은 8x8보다 큰 보드가 주어진다. 그러면 주어지는 입력 보드를 내가 8x8로 잘라야 한다는 뜻인가?
만약 그렇다면 저 답이 12가 나오는 것도 일리가 있다.

가설 : 입력으로 주어지는 보드를 내가 8x8 크기로 잘라야 한다

가설에 입각하여 위의 문제를 풀어본다

BBBWBWBW 1
BBBBWBWB 2
BBBWBWBW 1
BBBBWBWB 2
BBBWBWBW 1
BBBBWBWB 2
BBBWBWBW 1
BBBBWBWB 2

내 가설이 맞았다.
위 8x8 보드는 위의 10x13보드를 보고, 칠해야 하는 칸의 갯수가 최소일 것 같은 부분만 잘라서 다시 만든 것이다.
보드 옆의 숫자는 칠해야 하는 칸의 수이고, 다 더하면 12이다.

즉 문제풀이 순서를 크게 보면 다음과 같을 것이다.
1. 보드를 알맞게 자른다
2. 칠해야 하는 갯수를 센다
그런데 다시 생각해보면 보드를 알맞게 자른다는 행위는, 내 머릿속에서 잘라야 하는 보드 안의 칸의 구성이, 칠해야 하는 행위가 최소한으로 나올 것이라고 생각한 다음에야 행하여진다.
그러므로 올바른 순서는 다음과 같을 것이다.

칠해야 하는 칸 = a
1.
a가 최소한으로 나올 만 한 구역을 지정한다.
2.
지정된 구역을 8x8까지 정하고 a의 갯수를 센다.

# 풀이과정 2


문제를 푼지 9시간 정도 지났다 
결국 정답을 맞추긴 했는데 gemini의 힌트를 얻었다.

내가 틀렸던 부분은 8x8 블록을 한 행, 한 행씩 검사할 때 첫 번째 행과 두 번째 행에 사용해야 하는 마스크가 케이스마다 달라야 한다는 걸 코드에 명확하게 녹여내지 못했다는 것이다.
즉, 어렴풋이만 알고 코드에 적어내니, 코드가 디테일한 그 부분을 해결하지 못했던 것이다.

접근 자체는 정답에 가까웠으나 디테일한 부분의 구현을 하지 못한 것이 실패의 원인이었다.



```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        StringBuilder sb = new StringBuilder();

        // N,M입력
        StringTokenizer NandM = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(NandM.nextToken());
        int M = Integer.parseInt(NandM.nextToken());

        // 보드 입력
        String[] board = new String[N];
        for (int i = 0; i < N; i++) {
            board[i] = br.readLine();
        }
        
        String maskA = "BWBWBWBW";
        String maskB = "WBWBWBWB";
        int resultMin = Integer.MAX_VALUE;
        // 8x8 검사 블록이 아래쪽으로 1 이동
        for (int i = 0; i <= N-8; i++) {//for 1
            // 8x8 검사 블록이 오른쪽으로 1 이동
            for (int jj = 0; jj <= M-8;jj++) { // for 2
                //8x8 블록 검사
                int oneTask1Total = 0;
                int oneTask2Total = 0;

                // 8x8블록의 검사 행을 아래로 1 이동
                for (int k = 0; k < 8; k++) { // for 3
                    // 8x8블록의 현재 행을 검사하는 마스크는 이전, 다음 행과 반대여야 한다.
                    String currentmask1 = (k % 2 == 0) ? maskA : maskB;
                    String currentmask2 = (k % 2 == 0) ? maskB : maskA;
                    // 8x8블록의 검사 열을 오른쪽으로 1 이동
                    for (int l = 0; l < 8; l++) { // for 4
                        //현재 행 검사 - mask1
                        if (board[k+i].charAt(l+ jj) != currentmask1.charAt(l)) {
                            oneTask1Total++;
                        }
                        //현재 행 검사 - mask2
                        if (board[k+i].charAt(l+ jj) != currentmask2.charAt(l)) {
                            oneTask2Total++;
                        }
                    }
                }
                int taskMin = Math.min(oneTask1Total, oneTask2Total);
                resultMin =  Math.min(resultMin, taskMin);
            }
        }
        bw.write(String.valueOf(resultMin));

        bw.flush();
        bw.close();
        br.close();
    }

}
```

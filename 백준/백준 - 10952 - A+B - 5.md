첫 번째 시도 :
```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st;

        while (true) {
            st = new StringTokenizer(br.readLine());
            int A = Integer.parseInt(st.nextToken());
            int B = Integer.parseInt(st.nextToken());
            sb.append(A+B).append('\n');
            if ((A+B) == 0) break;
            bw.write(sb.toString());
        }
        bw.flush();
        bw.close();
        br.close();
    }
}
```

첫 번째 시도가 틀린 이유:

이 코드의 시도 결과는 출력 초과이다.

B의 범위는 다음과 같다 : B < 10

위 코드에서 while문의 break 조건 : (A+B) == 0

그런데 B는 음수가 될 수 있다. 그러므로  1 + (-1) 이 가능하다. 즉 이러한 테스트 케이스가 존재한다면 출력의 범위를 벗어난다.

그러므로 나는 break 가 실행될 수 있는 조건을 더욱 한정해야 한다.
break 실행 조건을 다음과 같이 설정하면 된다 : A == 0 && B == 0

시도 2의 결과 : 런타임 에러

에러 이유:
오류 원인은 총 2개이다.
1. 잘못된 StringTokenizer 생성 위치
2. bw.write()의 잘못된 위치

1.
st = new StringTokenizer(br.readLine()); 이 코드는 사용자의 입력을 한 줄 읽어서 StringTokenizer 객체로 전달하는 것이다. 테스트 케이스는 여러 개 이므로 위 코드는 반복문 안에서 여러 번 반복되어야 한다. 그러나 위 시도 2의 코드는 입력을 한 번만 받는다. 애초에 잘못된 코드이다.

2.
만약 StringTokenizer의 위치가 반복문 안으로 알맞게 들어갔다고 해도, bw.write()코드는 반복문 밖에 있어야 한다.
왜냐하면 bw.write()는 StringBuilder에 쌓인 문자열들을 한 번에 출력하기 위해서 한 번만 호출해야 하는 건데, 반복문 안에서 여러 번 호출하게 되면 쌓였던 데이터를 다시 한번 출력하게 되고 반복수는 기하급수가 된다.

백준 - 2745 - 진법 변환

https://www.acmicpc.net/problem/2745

아이디어:

입력되는 문자열 "ABC"이고 14진법이면
ABC에서 C 추출 -> C는 문자인가? 숫자인가? -> 분기에 따라 해당 값을 처리한 결과물은 숫자여야 함. (C는 12) -> 대기열 역할을 하는 배열에 쌓는다 -> B 추출 -> 위 과정 반복

대기열에서 하나 뽑는다 -> 맨 처음 숫자는 1의 자리 숫자니까 " $14^0 \times$ 대기열의 맨 처음 값" 을 계산한 값을 합계에 저장 -> 대기열 값을 다 쓸때 까지 반복 -> 결과 출력



```java
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
  
        String N = sc.next();  
        int B = sc.nextInt();  
  
        int[] arr = new int[N.length()];  
  
        int top = 0;  
        for (int i = N.length()-1; i >= 0 ; i--) {  
            char target = N.charAt(i);  
            int parsedTarget = 0;  
            if (Character.isDigit(target)) {  
                parsedTarget = target - '0';   // 'int' -> int  
  
            } else if (Character.isLetter(target)) {  
                parsedTarget = target - '7'; // char -> int  
            }  
            arr[top++] = parsedTarget;  
        }  
  
        int total = 0;  
        for (int i = 0; i < N.length(); i++) {  
            total += (int)Math.pow(B, i) * arr[i];  
        }  
  
  
        System.out.println(total);  
  
    }  
}
```

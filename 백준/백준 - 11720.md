백준 - 11720
https://www.acmicpc.net/problem/11720

먼저 N을 입력받는다.

N은 곧 숫자의 자리수를 의미한다.
N이 1이면 한 자릿수의 수가 입력된다.

N을 이용해 반복해서 문자열을 처리할 수 있는 방법??
문자열을 슬라이스 해야 하는데 자바로는 어떻게 하지?

String Class의 charAt()을 사용하자.


첫 번째 시도: 런타임 에러

```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
//        StringBuilder sb = new StringBuilder();  
  
        //입력  
        int N = Integer.parseInt(br.readLine());  
  
        //분해된 숫자 저장  
        int[] arr = new int[N];  
  
        //분해  
        for (int i = 0; i < N; i++) {  
            String s = br.readLine();  
            int num = s.charAt(i) - '0';  
            arr[i] = num;  
        }  
  
        //합산  
        int total = 0;  
        for(int i = 0; i < N; i++) {  
            total +=  arr[i];  
        }  
  
        //출력  
        bw.write(String.valueOf(total));  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
}
```

원인:

분해할 문자열을 입력 받을 때, for문 안에서 입력받는 게 아니라 밖에서 입력 받아야 한다.
(why?도 갔다 와서 입력하기.)

왜냐하면, 만약 사용자 입력이 "1 2"라면 '1', ' ', '2' 를 한 줄에 입력 받는다. 그런데 만약 for문 안에서 입력 받는다면 입력을 여러 번 받게 된다. 이 문제에서는 최대 2번 씩만 입력 받아야만 하기 때문이다.

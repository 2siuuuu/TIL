도레미파솔라시 도*

음계들이 연속적으로 올라가는지,
연속적으로 내려가는지,
둘 다 아닌건지 판단하는 프로그램을 작성하면 된다.

우선 한 줄의 입력을 받는다

입력값은 8개이다.

정답을 만들어놓고 비교하면 어떨까?
왜냐하면 우리가 눈으로 비교할 때도 머릿속으로 가장 이상적인 형태를 생각해 놓고 비교하여 어느 점이 다른지 판단하기 때문이다.

그렇게 한다면 답안지를 총 2개 준비해야 한다.
배열 2개를 만들어 오름차순 버전, 내림차순 버전을 준비한다.
예제 입력의 내용을 배열에 넣고 답안지 2개와 비교해야 한다.

배열 2개를 만드는 것 보다 카운터 라는 개념을 만들어서 계산하는 방식을 시도해보려고 한다

먼저 오름차순 카운터 변수와 내림차순 카우터 변수 두 개를 선언한다.

오름차순 카운터 변수 = 1
내림차순 카우터 변수 = 8

입력 한 줄을 받아 첫 번째 토큰을 target으로 지정한다.

첫 번째 단계는 이 입력이 오름차순인지, 내림차순인지, 아무것도 아닌지 판별하는 단계이다.
경우 1: target이 1인 경우.
이 경우엔 입력 전체가 오름차순일 것을 기대하고 카운터를 1 증가시킨다.
경우 2 : target이 8인 경우.
이 경우엔 입력 전체가 내림차순일 것을 기대하고 카운터를 1 감소시킨다.
경우 3 : 1도, 8도 아닌 경우.
무조건 mixed인 경우이다. 이 경우 반복을 중단하고 결과를 출력하여 프로그램 종료.

첫 번째 단계는 mixed인 경우를 제외하면 이 입력이 오름차순인지 내림차순인지 예상할 수 있는 단계이다. 

첫 번째 단계에서 둘 중 하나의 카운터가 변경되었다면, 이후에는 계속 변경된 카운터만 증감해야 한다. 

두 번째 단계부터 마지막 단계까지 반복하며 카운터가 끝에 도달했을 경우:
(오름차순 카운터는 8로, 내림차순 카운터는 1로)
그 시점에 입력 데이터가 오름차순인지 내림차순인지 정해지는 것이다.
중간에 카운터와 target이 불일치 하면 즉시 mixed인 것이다.

```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //숫자 입력받기  
        StringTokenizer st = new StringTokenizer(br.readLine());  
  
        // 출력 판별  
        int ascCounter = 1;  
        int descCounter = 8;  
        for (int i = 0; i < 8; i++) {  
            int target = Integer.parseInt(st.nextToken());  
            // 오름차순 판별  
            if (target == ascCounter) {  
                //카운터가 끝에 도달  
                if (ascCounter == 8) {  
                    bw.write("ascending");  
                    break;  
                }  
                ascCounter++; // 둘 중 하나의 카운터가 감소하거나 증가한 순간, 이후에는 변경된 카운터 만이 증감 가능.  
                descCounter = -1;  
                continue;  
            }  
  
            // 내림차순 판별  
            if (target == descCounter) {  
                //카운터가 끝에 도달  
                if (descCounter == 1) {  
                    bw.write("descending");  
                    break;  
                }  
                descCounter--;  
                ascCounter = -1;  
            }  
            else {  
                bw.write("mixed");  
                break;  
            }  
  
        }  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

백준 - 2563 - 색종이

https://www.acmicpc.net/problem/2563 색종이

넓이가 10,000인 도화지의 맨 왼쪽 맨 아래 부분에 넓이 100인 색종이를 붙인다

도화지 공간이 배열 공간이라면

색종이에 해당하는 넓이에 +1한다.
만약에 같은 공간에 색종이 99개를 붙여도 어차피 도화지 상의 검은 영역은 100이다.
그러므로 겹쳐도 아무 문제 없다.

주어지는 위치에 따라 색종이를 부착하며 그 공간에 1을 더하고,

마지막에 도화지 공간에서 0보다 큰 공간의 수를 세면 그게 검은 영역의 넓이이다.

```java
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);
  
        int[][] board = new int[100][100];  
  
        //색종이 그리기  
        int N = sc.nextInt();  
        for (int i = 0; i < N; i++) {  
            int W = sc.nextInt()-1;  
            int H = sc.nextInt()-1;  
  
            for (int j = 0; j < 10; j++) {  
                for (int k = 0; k < 10; k++) {  
                    board[H+j][W+k]++;  
                }  
            }  
        }  
  
        //넓이 구하기  
        int area = 0;  
        for (int i = 0; i < 100; i++) {  
            for (int j = 0; j < 100; j++) {  
                if (board[i][j] > 0) {  
                    area++;  
                }  
            }  
        }  
  
        System.out.println(area);  
  
  
    }  
}  

```

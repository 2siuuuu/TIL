백준 - 2292 - 벌집

https://www.acmicpc.net/problem/2292


1을 첫 번째 방, 그리고 그걸 둘러싼 방들의 모임을 도넛2,  도넛2를 둘러싼 방들의 모임을 도넛3 이라고 하자

1에서부터 도넛2 까지의 거리는 모두 2이다. 즉 도넛2의 모든 요소 중 하나의 값이 입력값으로 주어진다면 자기 자신을 포함하여 2 개의 방만 지나면 되므로 답은 2이다.
그럼 도넛 3에서는 달라질까?
도넛 3의 한 요소인 18이 입력값으로 주어졌다고 하자. 1까지 거리는 3이다.
8은? 3이다.
13도 ? 3이다. 즉 도넛 3의 어떤 방이든 1까지 최소 개수의 방을 지나기 위해 거쳐야 하는 방의 갯수는 3이다.

규칙이 보인다. 입력값의 방 번호가 도넛 4에 해당 하는 값 중 하나인 22라면 
그건 도넛 4 패밀리에 속하니까 답은 4일 것이다.

이건 어떻게 계산해 내면 될까?

도넛이 얼만큼의 일정 크기로 커지는 지 확인해보았다.
도넛은 정확히 6만큼 일정하게 커진다.
즉 첫 번째 방은 1이고

두 번째 방은 2 부터 7이며 
1 + 6 = 7이므로 도넛 2의 패밀리는 2~7까지 라는 뜻이다.
입력값이 5라면 그 방은 도넛 2에 있다는 것이고, 거리는 2라는 뜻이다.

내가 출력해야 하는 것은 거리다. 거리를 어떻게 출력해야 할까?
for문으로 반복을 해야 겠다.


```java
import java.io.*;  
import java.util.StringTokenizer;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //N  
        int N = Integer.parseInt(br.readLine());  
  
        int previous = 1;  
        if (!(N == 1)) {  
            for (int i = 0; previous < N; i++) {  
                int max = previous + (i * 6);  
                if (N <= max) {  
                    sb.append(i + 1);  
                    break;  
                } else {  
                    //다음 층 검사  
                    previous = max;  
                }  
            }  
        }  
        else sb.append(1);  
  
  
        //출력  
        bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

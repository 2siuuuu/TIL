백준 - 2798 - 블랙잭

https://www.acmicpc.net/problem/2798


카드 5장
5 6 7 8 9
일 때  3장의 합이 21과 최대한 가까우면 된다.

3장을 선택한다
`[][][]`

선택한 3장은 중복이 되어선 안 된다. 예를 들자면
`[5][6][7]`,
`[6][7][5]`
는 서로 중복되는 카드들이다.

즉 이렇게 중복되는 카드의 조합이 없도록 3장을 선택해야 하는데,
주어진 카드들에서 최대로 나올 수 있는 조합을 모두 선택해서 그 조합의 합을 확인해야 한다.

총 4장의 카드가 있고 다음과 같다고 하자 : 3,4,5,6

위 카드들에서 나올 수 있고 중복이 되지 않는 카드의 조합은 다음과 같다.
3+4+5
3+4+6
4+5+6

3+4+6 = 13이다. 13이 과연 M을 넘지 않으면서 가장 최댓값인지 확인하는 행위를 검사라고 한다면

검사 알고리즘이 어떻게 구현되어야 모든 카드 번호가 중복 없이 선택되도록 할 수 있는가..

우선 내가 가지고 있는 카드가 총 4장이라고 하자.
카드 번호들을 배열에 넣을 수 있다.
`[3][4][5][6]`
그리고 검사의 과정은 다음과 같다고 할 수 있다.
총 3개의 숫자 선택칸이 존재할 때 (3개의 카드를 선택해야 하므로) :
1. 첫 번째 자리 선택 `[3][?][?]`
2. 두 번째 자리 선택 `[3][4][?]`
3. 세 번째 자리 선택 `[3][4][5]`
4. 검사 `[3][4][5] = 12 vs M`
이것의 반복이다.

즉 반복문으로 풀 수 있다.

```java
import java.io.*;  
import java.util.StringTokenizer;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //NM  
        StringTokenizer st = new StringTokenizer(br.readLine());  
        int N = Integer.parseInt(st.nextToken());  
        int M = Integer.parseInt(st.nextToken());  
  
        // 카드 번호 입력 받기  
        StringTokenizer st2 = new StringTokenizer(br.readLine());  
        int[] numbers = new int[N];  
        for (int i = 0; i < N ; i++) {  
            numbers[i] = Integer.parseInt(st2.nextToken());  
        }  
  
        //중복되지 않는 3가지 조합의 합 검사  
        int curSum = 0;  
        int bestSum = 0;  
        for (int i = 0; i < N-2 ; i++) {  
            for (int j = i+1 ; j < N-1 ; j++) {  
                for (int k = j+1 ; k < N ; k++) {  
                    curSum = numbers[i] + numbers[j] + numbers[k];  
                    if (curSum <= M && curSum > bestSum){  
                        bestSum = curSum;  
                    }  
                }  
            }  
        }  
  
        sb.append(bestSum);  
  
        //출력  
        bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

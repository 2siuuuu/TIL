백준 - 2775 - 부녀회장이 될테야

https://www.acmicpc.net/problem/2775

2차 시도 성공 후 작성한 글

아파트에 몇 명 살고 있는지에 대한 문제랑 주인공이 부녀회장이 되고 싶은거랑 대체 무슨 상관인지는 모르겠지만 일단 풀었다.

이 문제는 0층에 몇 명이 사는지 일단 공개한다. 그리고, 입력으로 주어지는 층, 몇 호에 몇 명이 살아야 하는지 구해야 하는 프로그램을 만들면 된다.

만약 입력이 `1 3` 으로 주어진다면
1층 3호에 몇 명이 살아야 하는지 구하면 된다.

1층 `[][][?]`
0층 `[1][2][3]`

문제에 제시된 이상한 계약 조항에 의하면 각 층의 1호에 사는 사람은 무조건 1명이고
2호에 사는 사람은 바로 아랫층의 (1호에 사는 사람의 수) + (2호에 사는 사람의 수)이다.
즉 

시그마 (아랫층 1호에 사는 사람 수) + (아랫층 n호에 사는 사람 수)

그래서 1층 1호는 1명, 1층 2호는 1+2 = 3명, 3호는 1+2+3 = 6명.

그래서 1층 3호에 6명이 사는 것이다.

1층 `[][][6]`
0층 `[1][2][3]`

이걸 구하는 프로그램을 만드는 아이디어는 아래와 같았다.

어차피 입력으로 주어지는 층과 호수만으로 정답을 구할 수 있으니 입력으로 주어지는 호수의 길이 만큼의 공간을 가지는 배열을 활용하자.

구체적으로는 먼저 씨드머니 역할을 하는 0층 주민들의 수를 저장하는 배열을 선언한다.
`[1][2][3][...]` 이 배열의 크기는 입력으로 주어지는 호수와 동일함.
이 배열을 seed라고 하자

이후 나는 0층을 활용하여 1층의 인원들을 계산하고,
1층의 인원들을 활용하여 2층의 인원들을 계산하고,
쭉쭉쭉 계산해서 k층 까지 순차적으로 구할 것이다.

1층의 인원을 구한다고 했을 때, 나는 seed와 같은 크기의 임시 배열을 선언한다.
이 배열에는 seed를 이용하여 다음 층의 각 호의 인원 수를 계산해서 저장할 것이다.

임시 배열 `[][][]`
seed `[1][2][3]`

만약 1층의 계산을 완료해서 임시배열이 아래와 같이 다 찼다면
임시 배열 `[1][3][6]`
seed `[1][2][3]`

seed의 내용을 임시 배열의 값으로 덮어쓴다.
임시 배열 `[1][3][6]`
seed `[1][3][6]`

덮어 쓴 이후엔 다음 층의 계산을 위해 같은 작업을 반복하면 된다.

이후 모든 층의 계산이 완료되었을 경우 seed엔 이미 구하려는 층의 인원수들이 저장되어 있을 것이다. 출력하기 원하는 호수를 선택해서 출력하면 그게 답임.





1번째 시도 - 실패 (오답)
```java
import java.io.BufferedReader;  
import java.io.BufferedWriter;  
import java.io.IOException;  
import java.io.InputStreamReader;  
import java.io.OutputStreamWriter;  
import java.util.StringTokenizer;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        int T = Integer.parseInt(br.readLine());  
  
  
        for (int i = 0; i < T; i++) {  
            int floor = Integer.parseInt(br.readLine());  
            int roomNum = Integer.parseInt(br.readLine());  
  
            int[] arr = new int[roomNum];  
            //0층 거주 인원 초기화  
            for (int j = 0; j < roomNum; j++) {  
                arr[j] = j+1;  
            }  
  
            for (int j = 0; j < floor; j++) {  
                for (int k = 0; k < roomNum; k++) {  
                    int temp = 0;  
                    for (int l = 0; l < k+1; l++) {  
                        temp += arr[l];  
                    }  
                    arr[k] = temp;  
                }  
  
            }  
            sb.append(arr[roomNum-1]).append('\n');  
        }  
  
  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
  
  
}
```

실패의 이유: 
`arr[k] = temp;` <- 이 코드는 seed의 값을 바꾼다.
즉, 각 층의 인원 수를 계산 중인 와중에 seed를 바꿔버리면 결과 값은 정답과 거리가 멀어지는데 그걸 고려 못해서 틀렸음.

1차 시도 시점에는 임시 배열을 사용하는 아이디어를 떠올리지 못했고 이 이후에 그 아이디어를 차용해서 덮어쓰는 방법으로 문제를 해결했음.



2차 시도 - 성공

```java
import java.io.BufferedReader;  
import java.io.BufferedWriter;  
import java.io.IOException;  
import java.io.InputStreamReader;  
import java.io.OutputStreamWriter;  
import java.util.StringTokenizer;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        int T = Integer.parseInt(br.readLine());  
  
  
        for (int i = 0; i < T; i++) {  
            int floor = Integer.parseInt(br.readLine());  
            int roomNum = Integer.parseInt(br.readLine());  
  
            int[] arr = new int[roomNum];  
            //0층 거주 인원 초기화  
            for (int j = 0; j < roomNum; j++) {  
                arr[j] = j+1;  
            }  
  
            for (int j = 0; j < floor; j++) { //층별 계산 시작  
                int[] tempArr = new int[roomNum];  
                for (int k = 0; k < roomNum; k++) {  
                    int temp = 0;  
                    for (int l = 0; l < k+1; l++) {  
                        temp += arr[l];  
                    }  
                    tempArr[k] = temp;  
                }  
  
                System.arraycopy(tempArr, 0, arr, 0 , roomNum);  
  
            }  
            sb.append(arr[roomNum-1]).append('\n');  
        }  
  
  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
  
  
}
```

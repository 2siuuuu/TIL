https://www.acmicpc.net/problem/10818

1. N을 입력받는다

2. 두번 째 줄 문자열을 입력받는다.
int형 배열에 넣는다
두 번째 줄에 주어지는 정수 각각은 음수가 될 수 있다.
3. 배열의 요소들을 서로 비교하여 최댓값, 최솟값을 찾아 따로 저장한다.
먼저 배열의 첫 번째 요소를 최솟값으로서 저장한다.
두 번째 요소와 최솟값을 비교. 더 작은 값을 최솟값에 재대입한다.

4. 최솟값, 최댓값을 출력하기.


먼저 20
20을 최솟값에 배치
다음 10
10은 20보다 작아서 10을 최솟값에 배치, 기존 20을 최댓값에 배치
다음 35
기존 최솟값보다 큼, 기존 최댓값보다 큼. 최댓값에 35 배치.
다음 30
기존 최솟값보다 큼, 기존 최댓값보다 작음. pass
다음 7
기존 최솟값보다 작음. 최솟값에 7 배치. 기존 최댓값보다 작음. pass

끝.



하지만 원래 배열을 사용해서 풀려고 했지만 StringTokenizer를 이용하기로 했다.
왜냐하면 StringTokenizer 객체에서 nextToken()메서드를 호출하면 배열에서 하나씩 꺼내 쓰는 것과 마찬가지라고 생각했기 때문이다.

먼저 min, max 값을 선언한다.
min은 객체의 첫 번째 토큰으로 정한다. max는 0으로 설정한다.

만약 원래 정수들이 20 10 35 30 7였다면
min은 20에 들어간 것이고
나머지 10 35 30 7이 남은 것이다.

이제 10부터 마지막 7까지 검사하여 min값과 max 값을 찾으면 된다.

검사 시 매번 객체의 첫 번째 토큰을 pop 하는 것 처럼 사용할 수 있다.
그래서 pop된 요소를 target으로 지정하고, target이 min보다 작으면 교체, 그리고 기존 min값을 max값과 비교하여 더 크면 max값과 교체하는 알고리즘을 작성한다.

그렇게 하면 하나를 pop할 때마다 최소, 최대값을 모두 찾을 수 있다.
그것을 구현한 코드는 다음과 같다:
``` java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //1  
        int N = Integer.parseInt(br.readLine());  
  
        //2  
        //둘째 줄 입력 받음. 정수 문자열 A        StringTokenizer A = new StringTokenizer(br.readLine());  
  
  
        int min = Integer.parseInt(A.nextToken());  
        int max= 0;  
        for (int i = 0; i < N-1; i++) {  
            int target = Integer.parseInt(A.nextToken()); // 배열의 각 인덱스에 토큰 저장  
            if (min>target) {  
                int temp = min;  
                min = target;  
                if(temp>max) max = temp;  
            }  
            else if (max<target) max = target;  
        }  
  
        sb.append(min).append(" ").append(max);  
  
        //4  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
}
```

그리고 N에 해당하는 정수들이 모두 음수인 경우도 Edge Case임. 내 코드에서는.

```
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //1  
        int N = Integer.parseInt(br.readLine());  
  
        //2  
        //둘째 줄 입력 받음. 정수 문자열 A        StringTokenizer A = new StringTokenizer(br.readLine());  
  
  
        int token = Integer.parseInt(A.nextToken());  
        int min= token; int max= token;  
  
        for (int i = 0; i < N-1; i++) {  
            int target = Integer.parseInt(A.nextToken());  
            if (min>target) {  
                int temp = min;  
                min = target;  
                if(temp>max) max = temp;  
            }  
            else if (max<target) max = target;  
        }  
  
        sb.append(min).append(" ").append(max);  
  
        //4  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
}
```

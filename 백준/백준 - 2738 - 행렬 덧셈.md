백준 - 2738 - 행렬 덧셈

https://www.acmicpc.net/problem/2738

이 문제를 풀려면 두 행렬을 더하는 방법을 알아야 한다.

일단 입력 값의 형태부터 알아본다

```text
3 3
1 1 1
2 2 2
0 1 0
3 3 3
4 4 4
5 5 100
```

이 경우
`3 = N 3 = M` 이고

행렬 A
```
1 1 1
2 2 2
0 1 0
```
N개의 줄 -  1,2,0에 해당하는 세로 줄
원소 M개 - 맨 윗줄 1,1,1에 해당하는 가로 줄

행렬 B도 동일.


행렬을 더하는 방법
![](https://i.imgur.com/Chur9OT.png)


입력값:
N과 M은 100보다 작거나 같고, 행렬의 원소는 절댓값이 100보다 작거나 같은 정수

N과 M은 0~100

원소 : -100 ~ 100

***
풀이 방법

먼저 정답을 출력할 2차원 배열을 선언한다. 그 배열 이름은 answer라고 하자
->
맨 처음 입력되는 행렬 A의 원소가 입력된다
->
행렬 A의 원소를 answer의 1번 자리에 넣는다
->
행렬 A의 두 번째 원소가 입력된다.
->
answer의 2번 자리에 넣는다
->
행렬 A를 모두 answer에 넣는다.
->
행렬 B의 원소를 입력받는다.
->
answer의 1번자리의 원소와 행렬 B의 첫 번째 원소를 더해서 answer 1번 자리에 재 대입 한다.
->
answer의 2번자리의 원소와 행렬 B의 두 번째 원소를 더해서 answer 2번 자리에 재 대입 한다.
->
행렬 B의 모든 원소를 더할 때 까지 반복한다.
->
answer를 출력한다.


# 1차 시도 : 성공
```java
import java.io.*;  
import java.util.StringTokenizer;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //NM  
        StringTokenizer st = new StringTokenizer(br.readLine());  
        int N = Integer.parseInt(st.nextToken());  
        int M = Integer.parseInt(st.nextToken());  
  
        // answer 선언  
        int[][] answer = new int[N][M];  
  
        // 행렬A  
        for (int i = 0; i < N; i++) {  
            StringTokenizer elements = new StringTokenizer(br.readLine());  
            for (int j = 0; j < M; j++) {  
                answer[i][j] = Integer.parseInt(elements.nextToken());  
            }  
        }  
  
        //행렬B  
        for (int i = 0; i < N; i++) {  
            StringTokenizer elements = new StringTokenizer(br.readLine());  
            for (int j = 0; j < M; j++) {  
                answer[i][j] += Integer.parseInt(elements.nextToken());  
            }  
        }  
  
        //출력  
        for (int i = 0; i < N; i++) {  
            for (int j = 0; j < M; j++) {  
                sb.append(answer[i][j]).append(' ');  
            }  
            sb.append('\n');  
        }  
  
        //출력  
        bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

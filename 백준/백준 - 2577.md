백준 - 2577

https://www.acmicpc.net/problem/2577


ABC의 계산 결과를 문자열로 변환하고, 그 문자열을 A라고 하자

결과를 저장하는, 10개의 공간을 가진 배열을 만든다. 그 배열을 B라고 하자.

문자열 A가 123123이라고하자

A의 첫 번째 값은 1이다. 그 인덱스는 0이다.

숫자가 나올 때마다 그 숫자에 해당하는 B의 인덱스에 1을 계속 더한다 == 숫자가 몇 번 나왔는지 세는 행위와 같다.

A[1,2,3,1,2,3]

B[0,0,0,0,0,0,0,0,0]

A[0]의 값 == 1
이므로

B[1] 에 +1하면 된다. (숫자를 세는 행위)

그 결과 :

B[0,1,0,0,0,0,0,0,0]
만약 A의 두번 째 인덱스가 또 1이라면

B[0,2,0,0,0,0,0,0,0]

이런 식으로 숫자를 셀 수 있다.


```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
        StringBuilder sb = new StringBuilder();  
  
        //ABC 입력 받기.  
        int A = Integer.parseInt(br.readLine());  
        int B = Integer.parseInt(br.readLine());  
        int C = Integer.parseInt(br.readLine());  
  
        //계산 결과  
        String abcMul = String.valueOf(A*B*C);  
  
        //결과 출력 배열  
        int[] result = new int[10];  
  
        //계산  
        for(int i = 0; i < abcMul.length(); i++){  
            result[abcMul.charAt(i)-'0'] += 1;  
        }  
  
        //출력 문자열 생성  
        for(int i = 0; i < 10; i++){  
            sb.append(result[i]).append('\n');  
        }  
  
        //출력  
        bw.write(sb.toString());  
  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
}
```

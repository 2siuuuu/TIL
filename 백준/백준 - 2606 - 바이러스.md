# 아이디어

dfs 알고리즘을 실행하는 함수 내부에 감염된 pc의 갯수 저장하는 변수(infected)를 증가시키도록 하였다.
그리고 이 알고리즘은 1번 pc도 감염원으로 보기 때문에, 마지막 출력 결과에서 -1 해주면 정답이다.



# 코드

```java
import java.io.*;  
import java.util.*;  
  
public class Main {  
    public static boolean[] visited;  
    public static ArrayList<Integer>[] graph;  
    public static StringBuilder sb = new StringBuilder();  
    public static int infected = 0;  
  
    public static void main(String[] args) throws IOException {  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
  
        int computers = Integer.parseInt(br.readLine());  
        graph = new ArrayList[computers+1];  
        visited = new boolean[computers+1];  
        for (int i = 1; i <= computers ; i++) {  
            graph[i] = new ArrayList<>();  
        }  
  
  
        int pairs = Integer.parseInt(br.readLine());  
        //노드 간 연결.  
        for (int i = 0; i < pairs; i++) {  
            StringTokenizer st = new StringTokenizer(br.readLine());  
            int node1 = Integer.parseInt(st.nextToken());  
            int node2 = Integer.parseInt(st.nextToken());  
            graph[node1].add(node2);  
            graph[node2].add(node1);  
        }  
  
        //DFS 탐색    
dfs(1);  
        sb.append(infected-1);  
  
  
        //출력    
bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
  
    public static void dfs(int node) {  
        visited[node] = true;  
        infected++;  
        for (int next : graph[node]) {  
            if(!visited[next]) {  
                dfs(next);  
            }  
        }  
    }  
  
  
}
```
